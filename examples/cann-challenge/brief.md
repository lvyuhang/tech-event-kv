## 1. 活动
- **名称**：KV1「CANN 挑战赛全国总决赛」/ KV2「CANN挑战赛开发者冠军之夜」
- **时间 / 地点**：12 月 5 日｜中国·南京（全天：上午总决赛，下午颁奖典礼，晚上冠军之夜）
- **类型**：年轻赛事（genres A 的调性）+ 开发者大会的规格（genres B 的一个强符号、可延展），竞技感借电竞，但不做纯电竞

## 4. 视觉方向
- **一句话**：一个巨大的 3D 字母 "C"，白天是六路算力汇聚的赛场环，晚上是聚光灯下的冠军之环。
- **C 的四个意思**：CANN 的 C、C 位、赛场环、舞台框。两张 KV 用同一个 C、同一个机位、同一套构图，只换材质和光，所以能做成系统。
- **六大赛区**：C 的内圈分成六段灯带，六道光束各点亮一段，六色对应六个赛区。【假设】赛区名称未定，画面里不写赛区名。
- **南京**：C 立在几何化的中华门城门底座上（三孔拱 + 城垛轮廓），做成白色的建筑模型体块，不写实，也不用其他地标。【假设】
- **参考**：用户这次没有给参考图。竞技感从电竞借 3 个手法：超粗切角标题字、对冲光束、低机位仰拍；不借电竞的人物立绘、盔甲质感和满屏 HUD。

## 7. 标题字
- 超粗无衬线，**直立**，笔画转角切成 45° 斜角，横笔末端有一两处速度切口，字距收紧，有竞技感；**不把中文做成倾斜的假斜体**（playbook 19）
- "CANN" 用拉丁字，可以真斜体
- 只有赛事名一组做立体效果（KV1：墨色带一层很薄的电光蓝侧面；KV2：白色带金色侧面）。slogan 和信息是平面字
- 不用硬投影、粗白描边、贴纸外框
- 正式稿：模型出的中文只看效果，标题用矢量重排（playbook 18）

## 8. 材质与光
| 编号 | 材质 | 用在 |
|---|---|---|
| M1 | 白色光面陶瓷 (glossy white ceramic) | KV1 的 C 外表面 |
| M2 | 拉丝银 / 抛光金 (brushed silver / polished gold) | C 的倒角边（白天 / 夜晚） |
| M3 | 黑色镜面 (black mirror lacquer) | KV2 的 C 外表面 |
| M4 | 透明水晶玻璃 (clear crystal glass, slight dispersion) | 算子核心、奖杯 |
| M5 | 白色哑光建筑模型 (matte white architectural model) | 城门底座 |
| M6 | 自发光灯带 (emissive LED strip) | C 内圈、底座边缘 |

- **机位**：低机位，24mm 广角，微微仰视，C 有近大远小的透视
- **光**：只有一个主光（右上方的暖白光）；光束给 C 加彩色轮廓光；底座下面留实在的阴影；不起雾，不泛光
