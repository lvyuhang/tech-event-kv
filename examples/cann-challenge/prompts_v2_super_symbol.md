# v2 · 超级符号「城冠 C」· 参考迁移 + image-2 提示词

> 2026-11-02。用户看完 v1 草稿后说"可以造一个超级符号"，给了三张参考（`refs/`）。草稿在设计画布的第二组（v2）。

## 1. 问题出在哪（对照 playbook）
v1 的主体是一组东西：C 环、算子核心、六道光束、城门底座和地面。它是一个场景，单独拿出 C 来，看不出六大赛区，也看不出南京。所以它做不成 brief 要的"可拆解、可延展"的核心符号（playbook 8、L39）。三张参考的共同点是：画面中心只有一个能独立成立的 3D 品牌符号，所有动势都围着它转。

## 2. 三张参考的识别特征
| 参考 | 骨架 | 语言 | 识别特征 |
|---|---|---|---|
| ① 抖音「本地新推手」（日 / 夜两稿） | 符号居中偏上；丝带从两侧卷进来，绕住符号底部；符号后面是出血的巨大英文虚字；中文标题在符号正下方居中 | 白天：天蓝 + 珠光玻璃 + 橙粉丝带；夜晚：同一个符号和构图，换成金色钻面 + 液态金丝带 + 黑底 | 一个符号 + 一圈丝带 + 背后的英文巨字；日夜两版骨架相同 |
| ② 仓野品牌大会 | 奖杯居中；顶部一道光柱打下来；底部一圈螺旋光环；标题在左上 | 深蓝紫星空、金色和紫色的光带、玻璃气泡 | 顶光 + 螺旋光环 = "加冕" |
| ③ 抖音直播年度嘉年华 | 巨大的品牌符号套在一个光环里，立在透视大路的尽头；两侧是城市和丝带 | 高明度蓝紫、虹彩玻璃 | 符号 + 光环 + 汇聚的透视 |

## 3. 迁移表
| 槽位 | 参考里 | 换成 | 为什么 |
|---|---|---|---|
| 超级符号 | 抖音的音符 / 本地推的图形 | **城冠 C**：CANN 的 C，上沿长出 6 个城垛，每个城垛顶上一颗彩色宝石；C 的中心悬着一个算子立方体 | C = CANN / C 位；城垛 = 南京城墙 = 皇冠；6 个城垛 = 六大赛区；中心方块 = 算子 / C 位。一个形状同时说技术、赛事和南京 |
| 包裹元素 | 橙粉丝带 / 液态金丝带 | **六条丝带**，每条的颜色偏向一个赛区色（白天是虹彩玻璃，夜晚是液态金，带一点赛区色），从左右两边卷进来，绕住符号底部 | 六路汇聚，用参考的语言画出来，替掉 v1 的直线光束 |
| 背景巨字 | COMPETITION | 白天 "GRAND FINAL"，夜晚 "CHAMPION NIGHT" | 保持参考里的层次；英文是写定的通用词，不编造信息 |
| 顶光 + 光环（参考②③） | 奖杯上方的光柱、底部的螺旋光环 | 符号底部 2–3 圈椭圆光环；夜晚加一束顶光 | 夜晚的"C 位"＝聚光灯下的符号 |
| 南京 | 无 | 只在城垛里（不再用城门底座） | 不旅游化；底座拿掉后画面更干净 |
| 中文标题 | 符号正下方居中 | 同左：赛事名两行 + slogan + 信息胶囊 | 照搬骨架 |
| logo | 左上 / 右上 | 左上一排占位 | — |

**过约束**（playbook 3）：参考的标题在画面下部（草稿里是 52–82%）。用在主舞台 LED 和线上宣传时没问题；用在**合影墙 / 背景板**时，人会挡住下半部，要改成参考②的左上标题版：符号右移，标题放左上。这一版草稿还没画，等你确认主版再做。

## 4. KV1 · 全国总决赛 · 含字版（16:9）
```
【任务】为一场全国性技术赛事生成 16:9 横版主视觉 KV，用于主舞台 LED 和线上宣传。画面中心是一个巨大的 3D 超级符号，几条虹彩玻璃丝带从两侧卷进来绕住它；明亮、通透、年轻、有赛事规格感。参考近两年互联网大厂赛事 KV 的视觉语言：一个居中的 3D 品牌符号 + 流动丝带 + 背景英文巨字。不要传统科技大会的商务、深蓝、老气感。元素少而大。

【活动】CANN 挑战赛全国总决赛：全国六大赛区的选手汇聚南京。

【背景】高明度天空渐变：顶部天蓝 #7EC4FF，往下过渡到浅蓝 #CFE6FF，下部接近白色；底部有几团柔软的白色云雾，只在画面最下方；全画面细颗粒。

【背景巨字】符号后面一行巨大的英文 "GRAND FINAL"，白色半透明（约 60% 透明度），超粗压缩无衬线体，几乎撑满画面宽度，位于画面上半部，被符号挡住中间一部分。

【超级符号（画面水平居中，垂直位于 6%–50%，高度约占画面 44%）】一个巨大的 3D 字母 "C"：
- 粗壮、几何，开口朝右，正面略微转向右侧约 15°，能看到厚度和倒角；
- 材质是珠光虹彩玻璃 (iridescent pearl glass)，从白色过渡到淡蓝和淡紫，边缘有锐利的白色高光倒角；
- C 的上沿外侧长出 6 个方正的城垛（像城墙的垛口，也像一顶皇冠），从左到右均匀排开；每个城垛顶端嵌着一颗切面宝石，6 颗宝石的颜色依次是电光蓝 #2F6BFF、品红 #FF3D9A、青柠绿 #B6F23A、橙 #FF8A00、紫 #8B5CFF、青 #00D4FF；
- C 的正中心悬着一个透明水晶立方体 (clear crystal cube)，里面是 4×4 的发光蓝色小方块矩阵；
- 符号下方有 2–3 圈很细的白色椭圆光环，像符号立在一个发光的圆台上。

【丝带（六条）】六条宽而柔软的虹彩玻璃丝带 (iridescent glass ribbons)，表面有细密的平行丝纹和高光：三条从画面左边进来，三条从右边进来，在符号的底部绕成一圈，再向两侧飘出画面；每条丝带带一点不同的颜色倾向（蓝、粉、青柠、橙、紫、青），整体是柔和的粉彩虹彩，不刺眼。丝带不经过画面中下部的文字区，只在符号底部和画面最下方的两角出现。

【文字（符号正下方，水平居中，整体位于画面垂直 54%–82%）】（只出现下面引号里的文字，语言 zh，逐字准确，不要增删任何字）
- 第一行，墨色 #0E1124 粗体，宽字距："CANN 挑战赛"
- 第二行，全画面最大的中文，墨色超粗无衬线，字身直立不倾斜，笔画转角切成斜角，有竞技感，带一层很柔的蓝色投影："全国总决赛"
- 第三行，电光蓝 #1F56E6 粗体，宽字距，约为第二行的 1/3 大："以算为锋，奔赴金陵"
- 第四行，一个墨色圆角胶囊，里面白色字："12 月 5 日｜中国·南京"
- 左上角留出一条干净的横向区域放 logo，不要画任何 logo

【风格与光】高端 3D 渲染，C4D + Octane；珠光玻璃、水晶、虹彩丝带；明亮的天光从左上方来，符号有清楚的高光和柔和的阴影；通透，不起雾，不泛白；元素少而大。

【不要】深蓝科技风、地球、机器人、电路板纹理、写实城市、城门建筑、人物、抖音 logo 和音符、本地推图形、多余的符号、杂乱的气泡和碎片、倾斜的中文字、硬投影、粗白描边、乱码中文、额外的文字和 logo。
```

## 5. KV2 · 开发者冠军之夜 · 含字版（16:9）
```
【任务】为一场技术赛事的冠军之夜生成 16:9 横版主视觉 KV，用于晚宴主舞台 LED 和线上宣传。和白天的总决赛 KV 是同一个超级符号、同一个构图，夜晚版：符号变成金色，被一束顶光照亮，液态金丝带环绕。荣耀、热烈、年轻；不要传统颁奖礼的红金堂皇感。元素少而大。

【活动】CANN挑战赛开发者冠军之夜。

【背景】深邃的夜空：中心偏上是暗紫 #2A1C4A，向四周过渡到深紫黑 #0E0B24 和近黑；几道很细的流星光线；全画面细颗粒。

【背景巨字】符号后面一行巨大的英文 "CHAMPION NIGHT"，暗金色，非常淡（约 15% 不透明度），超粗压缩无衬线体，几乎撑满画面宽度，位于画面上半部。

【顶光】一束白色聚光灯从画面正上方笔直打下来，照在符号上，形成一个清晰的光锥，这就是 "C 位"。

【超级符号（画面水平居中，垂直位于 6%–50%，高度约占画面 44%）】和白天同样造型的巨大 3D 字母 "C"：
- 开口朝右，正面略微转向右侧约 15°；
- 材质是抛光金和钻石切面 (polished gold with faceted diamond-cut surfaces)，有锐利的反光和暗部；
- C 的上沿外侧 6 个方正的城垛（像皇冠），每个城垛顶端嵌着一颗切面宝石，颜色依次是电光蓝、品红、青柠绿、橙、紫、青；
- C 的正中心悬着一个水晶立方体，里面是 4×4 的金色发光矩阵；
- 符号下方有 2–3 圈金色椭圆光环，像螺旋光带围着一个发光的圆台。

【丝带（六条）】六条宽而柔软的液态金丝带 (liquid gold silk ribbons)，表面有细密的丝纹和强烈的高光：三条从左边进来，三条从右边进来，绕住符号底部再飘出画面；其中几条带一点赛区色的反光（蓝、品红、青）。丝带不经过画面中下部的文字区。

【文字（符号正下方，水平居中，整体位于画面垂直 54%–82%）】（只出现下面引号里的文字，语言 zh，逐字准确，不要增删任何字）
- 第一行，白色粗体，宽字距："CANN挑战赛"
- 第二行，全画面最大的中文，浅金色 #FFE7A3 超粗无衬线，字身直立不倾斜，笔画转角切成斜角，边缘有一圈细金光："开发者冠军之夜"
- 第三行，白色粗体，宽字距，其中字母 "C" 是金色 #F5C451："今夜有 C 位，荣耀正当燃"
- 第四行，一个金色细描边的透明圆角胶囊，里面白色字："12 月 5 日｜中国·南京"
- 左上角留出一条干净的横向区域放 logo，不要画任何 logo

【风格与光】高端 3D 渲染，C4D + Octane；抛光金、钻面、水晶、液态金丝带；主光是正上方的白色聚光灯，保留深沉的暗部；热烈但有秩序；不起雾，不过度泛光。

【不要】红色、红毯、香槟塔、传统颁奖礼、人群、写实人物、奖杯（符号本身就是奖杯）、地球、电路板纹理、抖音 logo 和音符、杂乱的星光和气泡、倾斜的中文字、硬投影、乱码中文、额外的文字和 logo。
```

## 6. 先单独出符号（推荐先做这一步）
超级符号要先定型，再放进 KV。用下面这条在纯色底上出 4 张，选定造型后作为两张 KV 的参考图输入：
```
一个巨大的 3D 字母 "C" 品牌符号，放在纯浅灰背景正中，45° 前侧视角，完整不出画。C 粗壮、几何，开口朝右，能看到厚度和倒角；C 的上沿外侧长出 6 个方正的城垛，像城墙垛口也像皇冠，从左到右均匀排开；每个城垛顶端嵌一颗切面宝石，颜色依次是电光蓝 #2F6BFF、品红 #FF3D9A、青柠绿 #B6F23A、橙 #FF8A00、紫 #8B5CFF、青 #00D4FF；C 的正中心悬着一个透明水晶立方体，里面是 4×4 发光小方块矩阵。材质：珠光虹彩玻璃 (iridescent pearl glass)，白色高光倒角。高端 3D 产品渲染，柔和棚拍光，地面有淡淡的接地阴影。不要文字、不要其他物体。
```
夜晚版把材质句换成"抛光金和钻石切面 (polished gold with faceted diamond-cut surfaces)，黑色背景，顶部一束聚光灯"。

## 7. 挑图看这几点
1. 先看符号：C 读得出，6 个城垛读得出（像皇冠，不像锯齿或齿轮），宝石刚好 6 颗
2. 缩到手机图标大小还认得出（城垛不能太细）
3. 丝带绕着符号底部，没有压到中文标题
4. 白天、夜晚两张的符号造型和位置一致
5. 中文逐字核对、字身直立
