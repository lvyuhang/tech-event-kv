# v3 · 大气版：赛场汇聚 + 徽章化超级符号

> 2026-11-04。用户看了 v2 出图（`kv1_v2_output.png`），觉得"还是不够大气"，发来 4 张电竞赛事氛围参考（`refs/ref4`–`ref7`）。

## 1. 四张参考的"大气"从哪里来
| 参考 | 骨架 | 大气靠什么 |
|---|---|---|
| ref4 KSL 王者荣耀主播联赛 | 徽章居中偏上；左红右蓝对冲；三个人物从三个方向飞向中心；能量流从两侧卷向徽章；大号 slogan 在底部 | 左右两种颜色对冲；所有动势都指向中心；徽章里带着赛事名 |
| ref5 Free Fire 世界赛 | 巨型奖杯立在金字塔台阶的尽头；人物从前景冲向奖杯，前景里有一只巨大的鞋底；两侧是城市；彩纸 | 极端透视（低机位广角）；前景特别大、远处的主体特别高 |
| ref6 全民手数王者杯 | 奖杯立在体育场中央的台子上；看台坐满观众；两侧高楼向中心汇聚；天空是漩涡；能量翅膀从两侧扫向奖杯；前景是举手的观众剪影 | 真实的场馆尺度；从前景剪影、看台到远处天空有三层景深；中心一团白光，四周压暗 |
| ref7 5E 城市争霸赛 | 仰视的漩涡隧道，四周高楼向中心倾倒；徽章顶上是城市天际线；人物从四周跳向中心 | 鱼眼仰视的放射构图；徽章上的城市剪影，和我们的"城冠"是同一个思路 |

**共同的规律**（v2 都没有做到）：
1. **有空间**：场馆、城市、台阶或漩涡，用透视把视线推向中心。v2 是一片平的天空。
2. **所有东西都朝中心汇聚**：能量流、人物、建筑全指向主体。这正好就是 brief 里的"六路汇聚"。v2 的丝带是横着摆的。
3. **中心强光、四周压暗或高饱和**：主体背后一团白光，画面边缘是饱和的深色。v2 整张都是浅粉彩。
4. **前景层**：观众剪影、人物或者大物件压在画面下沿，拉出三层景深。v2 没有前景。
5. **徽章化**：主体是一枚带赛事名铭牌的徽章，而不是一个光秃秃的字母。所以主体既是符号，也是标题。

## 3. KV1 · 全国总决赛 · 含字版（16:9）
```
【任务】为一场全国性技术赛事的总决赛生成 16:9 横版主视觉 KV，用于主舞台 LED 和线上宣传。要有顶级电竞总决赛的规格感和冲击力：巨大的场馆空间、所有能量向中心汇聚、中心强光、四周饱和压暗。年轻、热血、大气；不是传统科技大会，也不要写实人物和游戏角色。

【活动】CANN 挑战赛全国总决赛：全国六大赛区的选手汇聚南京，决出冠军。

【镜头】低机位，广角 20mm，从观众席的高度略微仰视舞台中央，强烈的透视，所有线条向画面中心汇聚。

【空间】一座巨大的环形电竞场馆内部，四周是层层叠叠坐满观众的看台（远处虚化，带点点手机灯光），场馆顶部敞开，露出天空；天空中心是一个旋转的白色光漩涡，正好在主体背后，越往画面四周越暗、越饱和（深蓝 #0B2A8F、电光蓝 #2F6BFF、边缘带一点品红）。

【主体：超级符号徽章（画面水平居中，垂直位于 8%–58%，高度约占画面一半）】立在场馆中央一座发光的圆形舞台上：
- 一个巨大的 3D 字母 "C"，粗壮、几何，开口朝右，正面略转向右侧约 15°，能看到厚度和锐利的倒角；材质是珠光虹彩玻璃和抛光银 (iridescent glass with polished silver bevels)，内缘有一圈电光蓝的发光边；
- C 的上沿外侧，6 个方正的城垛和 C 一体长出来，像城墙的垛口，也像一顶皇冠；每个城垛顶面嵌一颗小切面宝石，颜色从左到右依次是电光蓝、品红、青柠绿、橙、紫、青；
- C 的中心悬着一个清透的水晶立方体，内部是 4×4×4 的细小电光蓝光点阵（像张量），不要彩色方格面，不要像魔方；
- C 的下方横挂一块有厚度的金属铭牌，倒角锐利，深墨色底、银色描边，上面是白色粗体字 "CANN 挑战赛"。

【六股光流】六股宽大的算力光流从画面两侧卷向徽章中心，像能量翅膀：左边三股是暖色（品红 #FF3D9A、橙 #FF8A00、青柠绿 #B6F23A），右边三股是冷色（电光蓝 #2F6BFF、紫 #8B5CFF、青 #00D4FF）；光流有速度感和清晰的边缘，里面流动着少量发光小方块和极细的代码字符；光流在徽章背后交汇，迸出白光。

【前景】画面最下方一排举手欢呼的观众剪影，深色、虚化，只占画面高度的 15%，压住画面底部。

【文字（徽章正下方，水平居中，整体位于画面垂直 62%–86%）】（只出现下面引号里的文字，语言 zh，逐字准确，不要增删任何字；除了徽章铭牌上的 "CANN 挑战赛"，画面里没有别的文字）
- 第一行，全画面最大的中文，白色超粗无衬线，字身直立不倾斜，笔画转角切成斜角，字面有银白到淡蓝的金属渐变，带一圈很细的电光蓝外发光："全国总决赛"
- 第二行，白色粗体，宽字距，约为第一行的 40%："以算为锋，奔赴金陵"
- 第三行，一个白色细描边的透明圆角胶囊，里面白色字："12 月 5 日｜中国·南京"
- 左上角留出一条干净的横向区域放 logo，不要画任何 logo

【风格与光】顶级电竞赛事 KV 的 3D 渲染，C4D + Octane；主光是徽章背后的白色光漩涡，给徽章打出强烈的轮廓光；场馆和看台偏暗，形成明暗对比；高饱和，但颜色有秩序；有体积光，但空气通透，不要灰蒙蒙的雾。

【不要】写实人物、游戏角色、武器、钞票和金币、奖杯（徽章就是主体）、地球、机器人、电路板纹理、写实南京地标、红色主调的颁奖礼风格、杂乱的碎片和彩带、倾斜的中文字、硬投影、乱码中文、额外的文字和 logo。
```

## 5. 挑图看这几点
1. 第一眼有没有"场馆很大、徽章很高"的感觉：看台、光流、透视都要把视线推向徽章
2. 中心亮、四周暗或饱和，不是整张浅色
3. 徽章单独抠出来还成立：C、6 城垛、6 宝石、中心张量水晶、铭牌
4. 光流左暖右冷、汇进中心，没有压到下方的标题
5. 观众剪影只在最下沿，没有爬到标题区
6. 中文逐字核对、字身直立

## 6. 出图问题 → 补充句
| 问题 | 补充句 |
|---|---|
| 场馆太写实、像体育新闻照片 | `场馆是风格化的 3D 渲染，看台是简化的阶梯和虚化的光点，不是照片。` |
| 画面太满、太花 | `只有徽章、六股光流、场馆和前景剪影四样东西，没有其他物件和漂浮物。` |
| 徽章不够大 | `徽章是画面里最大的东西，高度约占画面一半，比看台上任何东西都大得多。` |
