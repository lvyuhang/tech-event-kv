# v4 · 风格尝试：参考微博「AI 画你猜」

> 2026-11-04。用户发来微博 × AI 创造营「AI 画你猜」长图（`refs/ref8_weibo_ai_huanicai.png`），说"这个风格我想尝试一版"。只迁移长图顶部的主视觉部分，改成 16:9 横版。

## 1. 参考拆解
**识别特征**（迁移后逐条核对）：
1. 标题用细的直角方括号框住关键词："AI[画你猜]"
2. 标题下方挂一块金属铭牌（"第二站"）
3. 主体是一座 3D 潮玩感的小建筑（AI 创造营展亭）：金属和玻璃，屏幕、灯牌、招牌，屋顶上空悬着一个 UFO
4. 青柠绿 + 炭灰金属 + 淡紫蓝天，三种颜色撑起全图
5. 像素元素：绿色像素方块、一条像素折线（黄色的 S）、像素箭头光标
6. 等宽小字标签（"/image""AI TOOLS"）和取景框式的角标 ⌜ ⌟
7. 建筑立在灰色地台上，地台边缘有一条草地，左边一根路牌杆

**骨架**：顶部 logo → 标题 + 铭牌 → 中部的主体建筑 → slogan 胶囊；居中纵向排列。
**语言**：
- 材质：炭灰拉丝金属面板 + 青柠绿描边；建筑是光面金属、玻璃和软胶，像潮玩模型
- 光：明亮的天光，阴影干净
- 字：超粗黑体 + 细直角括号；英文用等宽体

**和 brief 对照**：
- 年轻、活泼、科技、开发者：这个风格很强。
- 竞技感和荣誉感偏弱。靠计分屏 "FINAL" 和夜晚版的奖杯补一部分；如果还不够，再在场馆顶上加聚光灯。
- 大气：这个风格本身是"微缩模型"感，不靠空间尺度取胜。所以镜头要低机位仰视，让场馆显得高大，天空留大。

**和印刷约束对照**：标题和铭牌在上部，这一点合格。场馆在中下部，用在合影墙时会被人挡住一部分；主舞台 LED 可以。青柠绿是荧光色，CMYK 印刷会发灰，需要打样。

## 5. 挑图看这几点
1. 第一眼像不像参考：括号标题 + 铭牌 + 一座潮玩小场馆 + 青柠绿 / 炭灰 / 淡紫
2. 场馆是"建筑"，不是一台设备或一块屏幕
3. 像素流是一条带、六条车道，没有变成六条散乱的线
4. 中文逐字核对，括号只框住 "总决赛"
5. 青柠绿只用在描边、灯带和点缀上，没有铺满整个画面
