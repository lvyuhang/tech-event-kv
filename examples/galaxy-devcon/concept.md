## 3. 三层联想

- **字面层**：光标、代码行、提交（commit）、分支、合并（merge）、仓库、模型、token、部署
- **感受层**：汇聚、合流、点亮、被看见、从个体到整体、流动、生长、照亮夜晚
- **世界层**：银河、萤火虫、河流入海、支流汇成大河、夜航的渔火、河灯（放河灯）、水面倒映的星空、城市夜景航拍、鱼群、候鸟迁徙

**连接点**：git 的 branch → merge，和"支流汇成大河"是同一个形状。"星河"既是活动名，又是"许多光点组成一条河"。

## 6. 艺术指导：方向 A「星河汇流」

```
主张：每一行代码，汇成星河
画面：无风的夜晚，平静如镜的水面一直延伸到地平线。无数暖色的光点从画面近处漂来，
      像河灯又像萤火，在水面上汇成一条蜿蜒的光河，流向远方；
      光河在地平线处与天上的银河相接，银河从那一点斜着升向右上方。
叙事：近处的光点是一个个开发者（暖、个体）；远处的银河是汇聚后的整体（冷、宏大）。
颜色从暖到冷，就是"从个体到整体"。
融合手法：①光的溢出（光点照亮周围的水面）②倒影（银河和光点都倒映在水中）
          ③纵深分层（前景大而虚的光点 / 中景光河 / 远景地平线雾气）
          ⑤同源背景（天上的星和水上的光点是同一种光）⑦统一光照（光点是唯一光源）
配色：#05060D 夜 / #FFC978 暖金（近处光点）/ #C8FF8A 青柠 / #7FE3FF 冷青（远处与银河）/ #6B5BD6 余晖紫
字体气质：画面有机、诗意 → 文字精确、克制形成对比。
          主版 swiss：思源黑体 Heavy 中文 + Inter Display ExtraLight 英文 + 等宽标签
          延展 bleed：巨字 "GALAXY" 立在水面上，光河从字前流过
版式：光河从右下进入，流向画面中右的地平线，银河升向右上；左侧 45% 的夜空是文字区。
```

## 4–6 补充：主图与合成

- 主图：执行环境没有接生图模型，`heroes/` 里是按艺术指导用 numpy 点渲染的**替身图**，构图、光源和留白都按提示词设置。正式出图用 `prompts/A_hero_16x9.txt` 和 `prompts/A_hero_9x16.txt`。
- 用到的融合手法：①光的溢出 ②倒影（水面短倒影 + 银河倒映）③纵深（前景虚焦光点）⑤同源背景（星与光点是同一种光）⑦统一光照。
- 前景抠图：`hero_16x9_fg.png` 是近处光点；`hero_16x9_fg_galaxy.png` 额外包含银河，供 bleed 版让银河从巨字前面穿过。
- 字体配方（理性、精确）：cjk HarmonyOS Sans SC Black / display Inter Display 200 / mono JetBrains Mono。**渲染环境缺 HarmonyOS Sans SC 和 JetBrains Mono，回退为 Noto Sans CJK SC 和 DejaVu Sans Mono**（render.py 已报警告）。
- 排版系统：主版 `swiss`，延展 `bleed`（巨字 GALAXY 立在地平线上，`mark_baseline: 0.615`）。
