## 2. 主张

> 一个学生写下的**第一个算子**，是一段路的起点；跑完这段路，它就成了开源社区里的**第一份贡献**。俱乐部陪你跑完这一程。

## 3. 三层联想

- **字面层**：CANN、算子、Ascend C、kernel、张量、编译、测试、PR、Merged、GitCode、开源
- **感受层**：起步、第一次、跑通、接力、并肩、一起出发、毕业、成长、被看见
- **世界层**：**操场跑道**、起跑线、终点线、接力棒、运动会、新生报到、学号、课程表、草稿纸、社团招新摊位、校园地图、自行车

**关键联想**：开发者说代码"**跑通**了"。"跑通"和"跑道"天然相连，而操场跑道是每一所大学都有、每个学生都跑过的地方。

## 6. 艺术指导：方向 A「跑通」

```
主张：从第一个算子，到第一份贡献 —— 一段校园里的跑道
画面：俯视的操场一角。橙红色跑道从左下的起跑线出发，沿底部向右，再在右侧弯道向上转去。
      跑道围着的绿茵场是文字区。
      每条跑道上印着一行白色代码，一条比一条更进一步：
        1 算子 kernel 的函数签名 → 2 调用 → 3 新建分支 → 4 commit → 5 push → 6 PR Merged
      起跑线旁贴着"第一个算子"，弯道尽头的终点线贴着"第一份贡献"。
双关："跑通"——代码跑通了，人也跑完了这一程。
视觉装置：橙红跑道 + 白色分道线 + 跑道上的代码。可以延展成胸牌、横幅、贴纸、PPT 的分隔带。
主图路线：F 矢量插画（代码直出）。扁平图形不依赖生图模型，代码可以直接做到成品精度。
配色：跑道 #FF5B35 / 草坪 #2EB872、#38C47C（割草条纹）/ 纸面 #FFF4E4 / 贴纸黄 #FFD43B、天蓝 #4DA8FF / 墨色 #16161D
字体：标题 —— 粗壮、圆润、年轻（推荐得意黑、阿里妈妈方圆体）；代码 —— 等宽
排版：标题用白字写在草坪上，像操场上刷的字；Slogan 用荧光笔式的高亮；时间地点做成一张小票贴纸
```
