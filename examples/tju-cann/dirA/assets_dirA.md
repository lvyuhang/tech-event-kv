# 方向 A · 3D 潮玩 · 主视觉与漂浮元素（单独生成，后期合成）

## 思路
- **主视觉只做一个动作**：社区的手和学生的手交接"第一个算子"
- **漂浮元素每个都要同时和"技术"、"大学生"有关**：都是大学生身边真实存在的东西（学生卡、键盘、马克杯、草稿本、笔记本电脑），再给它加一点技术的内容。不用复古电脑、火箭、地球这类通用件
- 所有素材**单独生成**、风格统一，由我在排版里统一视角、比例、调色并合成，避免整张图的 AI 感

---

## 共用风格段（每个素材都粘贴这一段）

```
style: 3D 潮玩质感，C4D + Octane 渲染，中国互联网大厂校招 KV 风格（类似抖音校园招聘）。
  材质只用三种：磨砂亚克力（半透明、柔和）、光面软胶（饱满、圆润）、少量镜面金属。造型圆润、比例可爱但精致。
  配色：亮蓝 #2F6BFF、薄荷绿 #4FDDAA、淡紫 #B9A8FF、暖黄 #FFD45C，少量海棠粉 #FFB7C9，白和浅灰收住。
lighting: 一个柔和的主光源来自左上方 45°，右侧淡淡的冷色轮廓光；保留暗部和体积感，不要泛光、光晕、雾、镜头光斑。
camera: 略微俯视约 15°，50mm 镜头，物体完整在画面内，四周留白。
background: 纯白背景 #FFFFFF，物体孤立，没有地面、没有投影、没有其他物体，方便抠图。
quality: 干净、锐利、细节精致，没有任何多余文字和 logo。
```

**一致性技巧**：先生成主视觉，之后每个漂浮元素都把主视觉作为**风格参考图**一起传入。

## 1. 主视觉：交接第一个算子（16:9，2560×1440）

```
subject: 两只 3D 卡通手从画面左右两侧伸进来，在画面正中间交接一块小小的发光玻璃"算子键帽"。
  左手（社区）：白色卫衣袖子，袖口罗纹，袖口上一枚小小的软胶标签 "CANN"；掌心向上托着键帽，像在递出。
  右手（学生）：亮蓝色 #2F6BFF 连帽卫衣袖子，袖口罗纹，袖口一枚小标签 "TJU"，手腕戴一块简单的黑色运动手表；
    用拇指和食指轻轻捏住键帽的一角，正要接过来。
  算子键帽：圆角键帽造型，磨砂玻璃材质，薄荷绿内发光，顶面印清晰的 "add"；
    透过玻璃能看到里面两组小立方体（一组亮蓝、一组淡紫）流向中心，合成一组薄荷绿的小立方体。
  键帽周围一圈很小的白色闪光。
composition: 两只手横向贯穿画面上半部分（垂直 15%–45%），袖子从画面左右边缘出画；键帽在正中心偏上。
  画面其余部分是纯白背景，不放任何其他物体。
（接共用风格段，background 改为：纯白到极浅的淡蓝渐变，没有其他物体）
```

**备选动作**（不喜欢交接时再试）：两只手碰拳，碰拳处弹出那颗 "add" 键帽。

## 3. 合成布局（16:9）

见 `assets_layout.png`。
- 主视觉：两只手在上部中央，横向贯穿
- 漂浮元素沿**开口向下的弧形**环绕中央标题区：左上 ①、左中 ②、左下 ③（前景）；右上 ⑤、右中 ⑥、右下 ④；右下角 ⑦（前景）；⑧⑨ 点缀
- 中央（垂直 45%–80%）是标题区：黑色定制标题字
- 最下 12% 只放失焦的前景物件
- 合成时统一：视角、大小层级（中景物件不超过画面高度 22%，前景可以更大但失焦）、调色、颗粒；背景加淡蓝紫渐变、半透明棋盘格和少量像素碎片
