# 方向 A · 更多漂浮元素

## 你选的这个为什么成立
- **是一个"小设备"**，不是单个图标：厚实的镜面金属外壳 + 一块黑色小屏 + 一排半透明亚克力键帽 + 一根线缆和侧面的发光灯条。玩具感和精致感都有。
- **屏幕上的短句能读**："> hello, CANN_"，技术内容是被"显示"出来的，不是贴上去的。
- **CANN 四颗键帽**同时是品牌名和键盘。

下面的新元素沿用同一套语言：**一个大学生熟悉的小设备 / 小物件 + 一块屏幕或一个表面，用来"显示"一句很短的技术内容**。

## 共用风格段（加在原来的风格段后面）

```
object_language: 和参考元素一致——厚实圆润的镜面 / 拉丝金属外壳，半透明的亚克力或玻璃按键（亮蓝到薄荷绿渐变），
  需要屏幕的地方用黑色小屏 + 白色或薄荷绿的像素等宽字；可以有一根黑色线缆和一条发光灯条。
  物体完整、略微倾斜，纯白背景，没有投影。
```

**一致性**：把你这张"hello, CANN"作为风格参考图一起传入。

## 提示词


## 搭配建议
- 一张 KV 里漂浮元素仍然只放 **5–6 个**，其余留给延展物料（易拉宝、PPT、贴纸、周边）
- 推荐组合：**hello, CANN 设备**（已有）+ ★1 扭蛋机 + ★2 闹钟 11:08 + ★3 奶茶 + NPU 小芯片 + 海棠花枝（前景）
- 每种元素的大小要拉开层级：一个大（hello, CANN 设备）、两三个中、两三个小
