# 「> CANN_」大字主视觉 · Brief 摘要 + image-2 提示词包

## Brief 摘要
- **一句话**：把活动名做成主视觉——超大的 3D 立体字 "> CANN_"，像终端里刚敲下的一行命令。
- **一眼技术**：终端提示符 ">" 和光标 "_" 把字变成一行命令；键帽、+1 是开发者熟悉的东西。
- **一眼年轻**：糖果感的 3D 立体字、明快的亮蓝 + 薄荷绿、软胶星星和键帽轻轻散在四周。
- **大气**：一个主体（立体字）+ 一行大字（开发者俱乐部）+ 一条 slogan；元素少而大，远看清楚。
- **印刷板友好**：标题和 slogan 在上 2/3；下部只有边缘的键帽和渐变；平面部分是矢量，3D 字可以按板子尺寸重渲染。

## image-2 提示词 · 主体素材（推荐：只生成 3D 字，平面部分排版）

```
subject: 一行超大的 3D 立体字 "> CANN_"，像终端里刚输入的一行命令：
  最左边是一个 3D 的 ">" 提示符，最右边是一个横向的光标方块 "_"；中间是四个字母 "C" "A" "N" "N"。
  字体是几何感很强的超粗无衬线体，笔画饱满。
  材质：字母正面是光洁的白色软胶，带一层很淡的彩虹薄膜光泽（iridescent sheen）和清晰的高光；
    侧面厚度是半透明的淡蓝紫色果冻亚克力（translucent jelly acrylic），能透出一点光；
    ">" 和光标的侧面是薄荷绿 #4FDDAA，光标微微发光。
  每个字母略有不同的倾斜和高低，像刚被敲出来、轻轻跳动，但整体排成一行、读得很清楚。
  周围点缀：两颗软胶四角星（暖黄、白）、一颗小薄荷绿星星；左下一颗白色果冻键帽 "add"，右侧一颗薄荷绿键帽 "+1"（都可以出画）。
background: 亮蓝 #2F6BFF 到蓝紫 #5A5CFF 的平滑渐变，极淡的白色网格线；字母后方一团柔和的浅青色光晕。
composition: 立体字横贯画面上半部（垂直 12%–48%），略微仰视；下半部保持干净的渐变背景，留给排版。
lighting: 柔光棚照明，主光左上 45°，冷色轮廓光；保留暗部和体积；不要泛光、光斑、雾。
style: 3D 潮玩质感，C4D + Octane，物理正确材质，精致锐利，8K 细节。
text: 只出现 ">" "CANN" "_" "add" "+1"，逐字准确；不要其他文字和 logo。
avoid: 金属铬字、霓虹、赛博朋克、深色背景、电路板纹理、写实场景、人物、杂乱漂浮物。
```

## 印刷提示
- 3D 字用生图模型出图时，按板子尺寸至少出 4K 再超分到宽 ≥ 12000px；或者交给 3D 设计师按矢量字重建（推荐，边缘最干净）
- 平面文字、渐变、网格全部矢量排版
- 薄荷绿和亮蓝要打样，CMYK 下容易发灰
