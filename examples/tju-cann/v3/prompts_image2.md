# 天大 CANN 开发者俱乐部 · image-2 提示词

**用法**
- 每个方向两版：**含字版**让 image-2 直接出整张海报，看标题字和整体气质；**无字版**只出主视觉、空出标题区，之后再排版合成。
- 建议先用三个方向的**含字版**各出 2–4 张，当作真实的风格板来选；选定方向后，再用无字版出最终主图。
- 尺寸：16:9（如 2560×1440 或模型支持的最接近尺寸）。
- 可以把抖音参考图作为风格参考图一起传入（只借风格，提示词里已写明不复制构图）。
- logo 不让模型画。左上角留出空位，之后贴 logo 占位。

## 共用：风格段（三个方向都粘贴这一段）

```
style: 中国互联网大厂校园招聘 KV 风格，3D 潮玩质感（C4D + Octane 渲染），年轻、轻松、热闹、明亮。
  物件材质：通透玻璃、磨砂亚克力、软胶、毛绒、少量镜面金属；圆润造型，边缘有柔和高光和次表面散射。
  画面有前后景深：前景物件轻微失焦并带运动模糊、部分出画；中景物件清晰锐利。
background: 高明度渐变天空，上方淡蓝 #CBDDFF 过渡到淡紫 #DCCFFF，下半部分过渡到近白 #F7F9FF；
  上半部分飘着半透明的白色棋盘格（像设计软件里的透明背景格）和几块碎裂的像素方块；几颗小星星闪光。
palette: 主色是明亮的北洋蓝 #2F6BFF，点缀柠檬黄 #FFD84D、薄荷绿 #4FDDAA，少量珊瑚橙；整体高明度、不暗、不用深蓝科技风。
tech_details（必须清晰可读，技术元素长在物件上，不做背景贴图）:
  - 键帽上的字是真实的算子名：「add」「matmul」「softmax」
  - 代码窗口里的代码是 Ascend C 风格："__aicore__ void add_custom()" 和 "// my first operator :)"
  - 一枚绿色光面胶囊徽章写着 "Merged ✓"
  - 一块透明玻璃 AI 芯片，内部有发蓝光的核心和细密的电路纹
  - 像素风鼠标光标、像素风 "</>" 符号
campus_details: 天津大学元素适度出现：卫衣袖口上的 "TJU 1895" 刺绣徽章、一张校园卡、一本翻开的笔记本。
safe_area: 画面最下方 12% 只放柔和的装饰和地面反光，不放任何主体和文字（现场合影时会被人挡住）。
  左上角留出一块干净区域放 logo，不要画任何 logo 或商标。
avoid: 深色背景、深蓝科技风、电路板纹理铺满、蓝色光束、写实照片人物、真实品牌 logo、杂乱的小字、错误或乱码的中文、多余手指。
```

## 共用：文字段（含字版粘贴，无字版不贴）

```
text_elements（语言：zh，逐字准确，不要增删任何字）:
  title_area: 位于画面中部（垂直 38%–75%），水平居中，标题不被物件遮挡，物件只在标题四周环绕。
  line1（小，黑色粗黑体）: "天津大学"
  line2（最大，占画面宽度约 55%，黑色 #111 的定制标题字：笔画粗壮圆润、整体略向右倾斜、笔画末端带速度线收尾，像潮流品牌的手绘字）: "CANN开发者俱乐部"
  line3（中，黑色粗体）: "成立仪式暨校园宣讲会"
  slogan（中小，黑色粗体，可放在白色圆角对话气泡里）: "从第一个算子，到第一份贡献"
  info（小，黑色胶囊按钮里的白字）: "11月8日 ｜ 天津大学 XXX"
  除以上文字和 tech_details 里指定的字以外，画面上不要出现其他文字。
```

无字版改用这一段：

```
text_area: 画面中部（垂直 38%–75%，水平居中，宽约 60%）保持干净明亮的渐变天空，作为之后排版标题的区域；
  物件只在这片区域的四周呈弧形环绕。画面中不要出现除 tech_details 以外的任何文字。
```

## 挑图标准

按顺序看，前一条不过就不用看后一条：
1. 「连接」的动作一眼看得懂（A 是递和接，B 是一起按，C 是搭桥和走过去）
2. 标题区干净，标题没有被物件挡住；含字版的中文逐字正确
3. 技术元素可读：键帽上的算子名、代码、Merged 徽章
4. 手指数量和结构正确，没有多余的手
5. 整体明亮，没有发灰、发暗

**常见问题的改法**
| 出图问题 | 改提示词 |
|---|---|
| 物件太多太挤、挡住标题 | 删掉 left/right_cluster 里各一项；在 composition 末尾加"物件之间留出呼吸空间" |
| 中文标题出错 | 用无字版，标题之后排版；或只保留 line2 一行字测试 |
| 画成碰拳 / 握手（A） | 在 centerpiece 开头加："一只手掌心向上托着键帽递出，另一只手掌心向上准备接住" |
| 太像抖音 | 去掉风格参考图，只用文字提示词 |
| 颜色发灰 | 加"high-key lighting，明亮通透，高饱和点缀色" |
