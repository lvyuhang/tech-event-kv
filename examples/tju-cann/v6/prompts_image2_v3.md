# 天大 CANN · 新创意「一行代码，汇入社区」· image-2 提示词

## 从参考里学到什么

抖音生活服务这张的好，不在玻璃质感，而在**主体就是产品机制**：底部是搜索框，一条玻璃界面"缎带"从搜索框里升起、流出画面，电话、信封、金币、增长箭头这些"线索"都附着在缎带上。标题"一搜就来"被画面直接演了出来。

借的是这个方法：**把活动的机制做成一个连续的主体，漂浮物件只放这个机制产出的东西。** 不借搜索框和界面瀑布的具体造型。

## 这场活动的机制是什么

slogan「从第一个算子，到第一份贡献」本身就是一条路径：

**写下一行代码 → 算子把张量算出来 → 在昇腾芯片上跑通 → 提交 PR、被评审 → Merged，汇入社区**

所以主体是一条从终端输入栏里升起的玻璃缎带，自下而上依次经过这五站，最后汇入社区、流出画面。

## 每个物件在故事里是什么

| 物件 | 在故事里是什么 |
|---|---|
| 底部的终端输入栏 `>_ add_custom` + 回车键 | **起点**：学生敲下的第一行代码 |
| ① 缎带上的代码面板 | 算子代码 `__aicore__ void add_custom()` |
| ② 缎带表面流动的张量方块（蓝 + 紫 → 薄荷绿） | **"第一个算子"在工作**：两组方块合成一组 |
| ③ 缎带穿过的透明 NPU 芯片环 | **AI 计算**：算子跑在昇腾芯片上 |
| ④ PR 卡片 + 3 个评审头像 + "LGTM" | **社区接纳**：有人帮你看代码（连接） |
| ⑤ "Merged ✓" + 汇入更宽的光流，里面是很多贡献者头像小球 | **第一份贡献**，你成了社区的一员 |
| 输入栏旁的海棠花和"北洋 1895"徽章 | **天大**：这条路从校园出发 |

和抖音参考一样，**物件都附着在主体上**；漂浮在外面的只有海棠和徽章，它们标记的是起点。

1. 主体是**一条连续的缎带**，而不是一堆分开的卡片
2. 五站的顺序自下而上，能读出"写代码 → 算 → 跑 → 评审 → Merged"
3. 左侧 40% 干净，标题放得下
4. 海棠和徽章只在起点附近，不抢主体
5. 文字逐字正确（错了就删掉第 2、4 站的字，只保留 "add_custom" 和 "Merged ✓"）
