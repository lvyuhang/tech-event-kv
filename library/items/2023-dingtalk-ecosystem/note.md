## 好在哪 / 差在哪

（用户提供的正例，**待设计师补充**。）

执行者拆解：
- **整张图是一套网格**：浅灰底 + 细网格线，所有元素都是对齐网格的方块模块，拼贴在一起；标题坐在白色方块里，阶梯式错位。
- **模块种类**：纯色块 + 像素图标（对话气泡、机器人脸、`{-}`）、字母块（D I N G）、扁平花朵、彩色玻璃（Voronoi 马赛克）、阶梯条纹、渐变碎片、颗粒边缘的扁平云团、四角星。
- **撞色**：亮蓝为主，橙、绿、黄、天蓝撞色，黑白收住。
- **标题字**：超粗黑体 + 镂空切割（横向切口），几何、硬朗、有识别度。
- 不需要 3D 和生图模型，平面图形可以直接在代码里做出成品。

## 可借的手法

- 网格拼贴作为整套 VI：易拉宝、胸牌、PPT 都能用同一套模块重排
- 像素图标 / 字母块承载主题符号
- 镂空切字

## 不要学的地方

- 不复制具体模块组合与 DING 字母块
