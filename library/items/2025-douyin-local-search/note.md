## 好在哪 / 差在哪

（用户提供的正例，**待设计师补充具体评价**。）

执行者拆解：
- **主体是一个连续的结构，而不是一堆漂浮物**：底部是搜索框，一条由玻璃界面卡片组成的"缎带"从搜索框里升起、弯折、向上流出画面。
- **主体就是产品机制**：搜索 → 结果流出来 → 线索（电话、私信、团购券、上涨箭头）附着在缎带上。标题"线索商机，一搜就来"被画面直接演出来了。
- **漂浮物件都附着在主体上或从主体里飞出**，每个都是"线索"的一种：电话、信封、金币、增长箭头。
- **左文右图**：左侧 40% 是超粗黑体两行大字 + 两行副标 + 一个黑色胶囊标签；右侧 60% 是主体。
- 材质：玻璃 / 亚克力界面层叠、细密网点、发光边缘；配色蓝紫为主，粉、橙点缀。

## 可借的手法

- 把活动 / 产品的**机制**做成一个连续的主体（输入 → 过程 → 结果）
- 漂浮物件只放"结果"的不同形态，附着在主体上
- 左文右图版式，大字左对齐

## 不要学的地方

- 不复制搜索框 + 界面瀑布的具体造型
