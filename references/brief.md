# Brief 字段

## 必填（缺了要问）

| 字段 | 说明 | 例 |
|---|---|---|
| 活动名（中/英） | 主标题来源 | 2026 星河开发者大会 / Galaxy DevCon 2026 |
| 时间 | 日期，跨天写区间 | 2026.12.11–12.12 |
| 地点 | 城市 · 场馆，线上写"线上直播" | 中国 · 深圳 |
| 主办方 / 品牌 | 放 logo 用；有 VI 要拿到品牌色 | |
| 主用途 | 决定先做哪个尺寸 | 主会场大屏 / 公众号推文 / 海报 |

## 选填（缺了用默认值，在 concept.md 里写明假设）

| 字段 | 默认值 |
|---|---|
| slogan / 主题句 | 无则不放，不要替用户编 slogan；可以提 2–3 个候选让用户选 |
| 活动类型 | 按活动名推断：大会 / 峰会 / 黑客松 / 发布会 / 沙龙 / Meetup |
| 受众 | 开发者 |
| 调性 | 由活动类型决定，见下表 |
| logo 文件 | 无则用文字 logo（活动名缩写） |
| 必须出现的元素 | 无 |
| 禁用元素 / 竞品色 | 无 |
| 届数 | 无 |
| 需要的尺寸 | `sizes.md` 核心套装 |

## 活动类型 → 默认调性

| 类型 | 调性 | 倾向方向（见 directions.md） |
|---|---|---|
| 年度开发者大会 / 技术峰会 | 宏大、权威、有未来感 | D1 暗场流光、D2 白底光谱玻璃、D4 巨构字形 |
| AI / 大模型主题 | 智能、生长、有温度 | D2、D3 流体有机、D7 光场粒子 |
| 黑客松 / 编程挑战 | 年轻、有冲劲、玩味 | D5 终端代码、D6 像素与网格、D8 拼贴 |
| 产品 / 版本发布 | 聚焦、精致 | D4 巨构字形、D2 |
| 技术沙龙 / Meetup | 轻松、社区感 | D5、D6、D8 |
| 开源 / 社区活动 | 开放、协作 | D6、D8 |
| 安全 / 基础设施 | 稳固、精密 | D1、D4 |

## 一次性提问模板

> 开始设计前需要确认几项：
> 1. 活动全称（中英文）和 slogan（没有的话我可以给几个候选）
> 2. 时间、地点
> 3. 主办方 logo 和品牌色（有 VI 规范的话一起发我）
> 4. 最先要用在哪：大屏、推文头图还是海报？
