# 案例拆解

拆解参考图时用同一格式：符号 / 处理方式 / 材质 / 背景 / 配色 / 版式 / 信息层级 / 可迁移的点。拆解用于提取方法，不要照抄具体形态。

---

## A. Alibaba.com FY27 Global Channel Partner Summit

| 项 | 内容 |
|---|---|
| 符号 | 关键词 "Global"，草书字形 |
| 处理方式 | 整体放大、出血到右上；近大远小的透视，前景字母虚焦 |
| 材质 | 流体玻璃管，内部有橙、品红、青、绿的彩虹流光 |
| 背景 | 近黑深紫，左下一团紫色雾光 |
| 配色 | 深紫黑底 + 多彩光；文字纯白 |
| 版式 | L1 左文右图，文字压在主体前景的虚焦区上 |
| 信息层级 | logo（左上）→ H1 "SUPPLY DIVERSITY" + 小字 "GROWTH PROSPERITY" → slogan 两行 → 底注全大写宽字距 |
| 方向归类 | D1 暗场流光 · 造境手法：置换（关键词 → 流体玻璃）· 排版：接近 `swiss` |
| 可迁移的点 | ① 用一个英文关键词做主体，比用 logo 更有叙事；② 虚焦前景制造纵深，同时给文字让出可读区；③ 文字只有 4 层，克制 |

## B. 2022 世界设计之都大会（WDCC）元宇宙分会场

| 项 | 内容 |
|---|---|
| 符号 | logo 中的 W 和 C 字形 |
| 处理方式 | 作为容器：字形做成大块透明彩色玻璃，内部合成全球城市地标天际线 |
| 材质 | 高饱和透明玻璃块（青、绿、黄、灰、紫、品红） |
| 背景 | 纯白 |
| 配色 | 白底 + 光谱色带，黑字 |
| 版式 | L3 右信息栏：左侧主视觉，右侧用细线分隔出分会场名、子品牌 logo、日期 |
| 信息层级 | 小 logo → 中文大标题 → 英文全称 → 主图 → 右栏（分会场 / 子品牌 / 日期）→ 底部 slogan |
| 方向归类 | D2 白底光谱玻璃 · 造境手法：容器 · 排版：右信息栏，接近 `swiss` 的变体 |
| 可迁移的点 | ① logo 字形作为容器，可以装进"城市""代码""数据"等任何内容；② 右信息栏适合多会场、多日期的复杂活动；③ 信息多时用细线做分隔，不用色块 |

**注意**：容器内的合成内容（城市照片）不适合让生图模型一次生成。做法是分两张图生成：玻璃字形 + 内容图，再在排版层用蒙版合成。模板目前只支持单张主图，这类需求要在交付说明里标注"需后期合成"。

## C. TCL 全球技术创新大会 TIC 2024

| 项 | 内容 |
|---|---|
| 符号 | 活动缩写 "TIC" 的字形 |
| 处理方式 | 拆解散落：字母拆成多块，悬浮在空中，大小不一形成纵深 |
| 材质 | 彩色亚克力 / 玻璃，多层叠合，边缘有色散 |
| 背景 | 纯白，带一点淡彩色投影 |
| 配色 | 白底 + 红、蓝、绿、橙、紫；标题用渐变色彩字 |
| 版式 | L1 左文右图 |
| 信息层级 | 彩色字 logo "TIC 2024" → 中文大会名 + 英文全称 → slogan（中）+ 英文 → 地点 · 日期 |
| 方向归类 | D2 白底光谱玻璃 · 造境手法：定格（字母碎裂的瞬间）· 排版：`swiss` |
| 可迁移的点 | ① 主图的碎片配色和标题 logo 色彩呼应，图文一体；② 拆解散落天然留出了文字空间；③ 中英双语分行排，层级清楚 |

## 三个案例的共同规律

1. 主体都是**字形**（关键词 / logo / 缩写），没有一个用了具象的"科技图片"。
2. 都只有**一种材质**：玻璃 / 透明材质是近几年技术活动的主流选择。
3. 文字全部是**干净的无衬线体**，没有特效字。
4. 背景都很**单纯**：纯白或单色渐变，复杂度全部交给主体。

## 这些案例的上限在哪里

三个案例的概念都在 L1.5–L2（字形 + 材质），靠的是顶级 3D 执行力：材质、光、后期都非常精细。用生图模型做时，执行力的上限更低，单靠"字形 + 玻璃"很容易变成廉价的 L1。所以本 skill 要求概念上至少达到 L2、最好有一个 L3，用叙事弥补执行力的差距（见 concept.md 第 4 步）。
