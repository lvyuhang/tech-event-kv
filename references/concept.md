# 概念推导：从主题到视觉隐喻

KV 出来很直白，问题几乎总在这一步：拿到"AI 大会"就画神经网络，拿到"云"就画云朵。这一步走的是"关键词 → 图标"，跳过了设计师真正在做的事：**先想清楚要说什么，再到物理世界里找一个有同样感受的画面。**

本文件规定的流程必须完整执行，并把每一步的产出写进 `concept.md`。不允许跳步直接给方向。

---

## 第 0 步：先看活动名本身

很多活动名本身就是现成的画面（"星河""极光""云栖""火山""繁星"），而且这是**别的活动无法复用的**画面，独特性天然最高。动手发散前先问：活动名、品牌名、slogan 里有没有一个可以画出来的东西？有的话，至少有一个概念要从它出发。

## 第 1 步：写一句主张（Thesis）

不是复述活动名，而是回答：**这场活动想让观众相信什么、感受到什么变化？**

句式：`[主题] 让 [谁/什么] 从 [状态 A] 变成 [状态 B]`

| 活动 | 差的主张（复述） | 好的主张（有变化、有张力） |
|---|---|---|
| AI 原生开发者大会 | AI 赋能开发者 | AI 让代码从"被写出来"变成"自己生长出来" |
| 48 小时黑客松 | 创新挑战赛 | 48 小时把一个念头压缩成一个能跑的东西 |
| 云原生技术峰会 | 拥抱云原生 | 基础设施从"看得见的机房"变成"像空气一样无处不在" |
| 数据库技术大会 | 数据驱动未来 | 数据库是一家公司的长期记忆，一层层沉积、永不丢失 |
| 安全大会 | 守护数字安全 | 最好的安全是看不见的：它在，但你感觉不到 |

slogan 有内容时从 slogan 推；slogan 是空话时（"智领未来"之类）从活动的实际内容推，并在 concept.md 里写明。

## 第 2 步：三层联想

围绕主张，分三层写词，每层至少 8 个：

1. **字面层**（技术本身）：代码、模型、GPU、括号、光标、终端、节点、数据流……
   → 这一层的词**只能作为"符号"出现，不能作为画面本身**。
2. **感受层**（主张带来的感受/动作）：生长、涌现、共振、压缩、解放、沉积、渗透、编织、苏醒、汇流……
3. **世界层**（物理世界里有这种感受的东西）：
   - 生长 → 菌丝网络、珊瑚、晶体析出、藤蔓攀援、根系、发芽的种子
   - 涌现 → 椋鸟群、鱼群、萤火虫、沙丘纹理、雪花结晶
   - 压缩 → 地层、钻石、压花、折纸、沙漏、一捆光
   - 无处不在 → 雾、空气中的光尘、潮汐、水面倒影、风吹过麦田
   - 沉积/记忆 → 冰芯、年轮、岩层、琥珀、图书馆书脊
   - 守护 → 极细的蛛丝、雾中的灯塔、肥皂泡膜、鸟巢

**好的隐喻 = 一个字面层符号 × 一个世界层画面**，由感受层连接。

## 第 3 步：用造境手法发散（至少 9 个概念）

每个手法至少产出 1 个概念，总数 ≥ 9。每个概念写成**一句可以被画出来的话**（有主体、有动作、有环境）。

| # | 手法 | 公式 | 例（AI 原生开发者大会） |
|---|---|---|---|
| 1 | **置换** | 符号的材质换成世界层的东西 | 一对巨大的花括号 `{ }` 由正在生长的珊瑚构成 |
| 2 | **转化中** | A 正在变成 B 的瞬间 | 一行代码的字符从屏幕边缘飘出，一边飘一边变成发光的种子落进土壤 |
| 3 | **尺度反差** | 微小的东西变成宏大景观，或反之 | 一个闪烁的光标 `▍` 像一座灯塔立在夜晚海岸，光束扫过海面 |
| 4 | **景观化** | 符号成为可以进入的地形/建筑 | 字母 "AI" 是一道巨大的峡谷，峡谷底部有一条光的河流 |
| 5 | **容器** | 符号的轮廓里装着另一个世界 | 透明的 `</>` 玻璃体内部是一片正在下雨的森林 |
| 6 | **涌现** | 成千上万个小单元聚合成符号 | 夜空中数万只萤火虫正在聚合成一个光标的形状，边缘还在散开 |
| 7 | **定格** | 一个动态过程被冻结 | 水滴落入水面溅起的皇冠形水花，在最高点凝固成玻璃 |
| 8 | **双关** | 一个形看起来同时是两样东西 | 层层叠叠的半透明神经网络层，侧面看是一座山脉的等高线 |
| 9 | **光影** | 物体和它的影子 / 倒影讲两件事 | 一颗普通的种子，在水面的倒影是一棵由光纤组成的大树 |
| 10 | **悖论** | 物理上不可能的结构 | 一条莫比乌斯环形的河流，水流上漂着的是发光的字符 |

## 第 4 步：直白度分级

每个概念标一个等级：

| 级 | 定义 | 例 | 处理 |
|---|---|---|---|
| **L0 字面** | 直接画主题本身或其俗套图标 | 机器人代表 AI，云朵代表云 | ✗ 直接淘汰 |
| **L1 符号** | 技术符号 + 通用科技材质 | 发光神经网络、蓝色数据流、玻璃括号悬浮 | ✗ 不能作为最终方向 |
| **L2 符号转化** | 技术符号 × 一个世界层元素 | 由珊瑚构成的花括号 | ✓ 可用 |
| **L3 隐喻** | 画面本身就讲了主张，技术符号退到暗示 | 萤火虫聚合成光标 = "涌现" | ✓ 最好，至少要有一个 |

> 参考：三张参考 KV 都在 L1.5–L2 之间（字形 + 材质 + 环境）。它们成立是因为执行完成度极高。我们的生图模型执行力不如顶级 3D 设计师，所以概念上要更高一级来弥补。

## 第 5 步：打分与筛选

每个 L2 / L3 概念按下表打分（1–5）：

| 维度 | 问题 |
|---|---|
| **独特性** | 把活动名换成另一场技术活动，这张图还成立吗？成立 = 低分。落在参考调研的**红海清单**里（research.md）= 最高 2 分 |
| **3 秒可读** | 缩小到手机屏幕上，3 秒内能看出主体是什么吗？ |
| **主张契合** | 画面是否讲了第 1 步的那句主张？ |
| **可生成** | 生图模型能稳定画出来吗？（多主体精确交互、精确数量、文字形态 → 难） |
| **留白友好** | 是否天然有一块安静区域放文字？横竖两版都能构图吗？ |

**总分 ≥ 18 才能进入方向**。选 3 个，必须满足：
- 至少 1 个 L3
- 来自至少 2 种不同的手法
- 至少一深一浅（背景基调）

## 第 6 步：把概念写成"艺术指导"

每个入选概念写一段艺术指导（Art Direction），这是后面写提示词和排版的唯一依据：

```
### 方向 A：萤火（涌现）
主张：AI 让代码从"被写出来"变成"自己生长出来"
画面：初夏夜晚的湿地上空，数万只萤火虫正在聚合成一个巨大的光标 ▍，
      光标下半部分已经成形、明亮，上半部分还是散开的光点；
      光点在下方的水面形成倒影。
为什么成立：光标 = 写代码的起点；萤火虫自发聚集 = 涌现、自生长。
直白度：L3      手法：涌现      得分：独 5 / 读 4 / 契 5 / 生 4 / 留 4 = 22
环境与融合：主体本身是光源，暖绿色光照亮下方的芦苇和水汽；
          远处地平线有极淡的冷蓝余晖；雾气在水面低处。（见 integration.md）
配色：#05080A 夜 / #C8FF6A 萤光 / #FFD58A 暖芯 / #2A4B5C 远景
字体气质：安静、精确，与有机画面形成反差 → swiss 排版系统，细字重英文 + 粗中文
版式：主体在右 60%，左侧水面上方的夜空是文字区
```

## 常见失败与修正

| 失败 | 症状 | 修正 |
|---|---|---|
| 关键词直译 | "云原生" → 画云朵 | 回第 2 步，从感受层出发 |
| 符号堆砌 | 一张图里有括号、芯片、神经网络、地球 | 只保留一个符号，其他删掉 |
| 只换材质不换意义 | 玻璃括号 → 金属括号 → 液态括号 | 这是同一个 L1 概念的三种皮肤，要换手法 |
| 概念太复杂画不出 | "三个人在桥上传递发光的方块，桥由代码组成" | 每个概念只有一个主体 + 一个动作 + 一个环境 |
| 隐喻太远看不懂 | "数据库 = 琥珀里的蚊子" 但画面里看不出任何数据的意思 | 字面层符号要留一点暗示：琥珀里封存的是一行行发光的字符 |

## 俗套清单（默认禁用，用户坚持除外）

二进制数字雨、发光大脑、机械手与人手指尖相触、蓝色地球 + 连线、整块电路板贴图、人形机器人脸、锁 + 盾、齿轮、灯泡、"科技蓝"渐变 + 白色光点、全息投影 UI 面板、矩阵绿色代码、握手、火箭发射、拼图块。

## 技术符号素材（字面层，只作为被转化的对象）

| 领域 | 符号 |
|---|---|
| 通用编程 | `{ }`、`< />`、光标 `▍`、`$` 提示符、缩进阶梯、git 分支线、`;` |
| AI / 大模型 | 层叠平面、注意力连线、token 碎片、星形 ✦、渐进收敛的点云 |
| 云 / 基础设施 | 模块方块、容器嵌套、等距结构 |
| 数据 | 流线、等高线、柱体、散点 |
| 芯片 / 硬件 | 晶圆同心圆、走线节奏 |
| 安全 | 晶格、同心层、锁扣结构 |
| 开源 / 社区 | 环、交织、积木、大量小点组成大形 |
| 活动名 | 首字母、缩写、年份数字（≤ 6 个字符） |
