# 时代感、识别度与大字细节

概念对了，执行仍然可能"老气"或"简陋"。这三类问题在评审里最常出现，而且模型自评时最容易漏掉，因为它们不是"错误"，是"过时"和"空"。

---

## 一、老气信号 vs 当代信号

渲染完之后逐条对照。命中 2 条以上老气信号，就要回到风格和排版重做。

| 维度 | 老气（约 2012–2019 的常见做法） | 当代（2023 年以后技术品牌常见的做法） |
|---|---|---|
| 画面类型 | 写实"壁纸"：星空、银河、星云、城市夜景航拍、地球 | 图形化 / 生成式：点阵、字符、线、粒子构成的**设计出来的形**；或高度克制的单一 3D 物体 |
| 光效 | 镜头光晕、金色散景（bokeh）、大面积辉光、光束 | 光只出现在一处（汇聚点 / 核心），其余部分锐利干净 |
| 配色 | 紫 + 金、蓝 + 紫渐变、彩虹全光谱 | 近黑 / 近白 + **1 个**强调色（荧光绿、电光蓝、橙），或单色系 |
| 大字 | 渐变填充、外发光、斜面、金属质感的英文巨字 | 实心、精确、字距收紧；或有**内部细节**（纹理、网格、穿插） |
| 排版 | 居中堆叠、标题加光晕、副标题加大字距铺满 | 网格、锁定组合（lockup）、编号与标签、等宽小字注释 |
| 质感 | 塑料感 3D、过度锐化、HDR 风 | 细颗粒、精确的细线、印刷感 |
| 元素 | 多个装饰元素并存 | 一个符号、一种语言（点 / 字符 / 线）贯穿全部 |

**注意**：写实风格本身不等于老气。写实做得当代的条件是：极度克制（一个主体、大面积留白）、非常规的取景或色彩、摄影级质感。生图模型默认产出的"壮丽写实"几乎都落在老气一侧。

## 二、识别度：一个能被认出来的"装置"

遮住所有小字，只看缩略图：能认出这是"这个活动"吗？还是任何一个科技活动都能用？

识别度来自一个**可拥有的视觉装置**（device），满足：
1. **来自活动本身**：活动名、品牌名、主张里的形（例："星河"两个字本身、汇聚的流）
2. **形状简单**：缩到 100px 宽还能认出
3. **能贯穿所有物料**：主屏、海报、胸牌、PPT、动效都能用同一个装置

常见的装置做法：
- **品牌字做巨字**：活动名里最有辨识度的 1–3 个字（中文）或 ≤ 6 个字母，做成锁定组合的主体（`lockup` 排版系统）
- **一个专属的形**：一条特定的曲线、一个特定的构图（例：从散落到汇聚再升起的流）
- **一种专属的材质语言**：例如"一切都由真实代码字符构成"

主视觉画面再好看，如果没有装置，换一个活动名照样成立，识别度就是低分。

## 三、大字细节：放大就需要细节

字号越大，越会暴露"没有内容"。一个占画面 40% 的字，如果只是一块实心或渐变色，在大屏上看就是一大块色块，显得简陋。

巨字至少满足下面一条：
- **内部细节**：用纹理填充（`mark_fill: texture`，例如密排的代码文字），近看有内容，远看是实心字
- **穿插**：主体或环境元素从字前面穿过（`hero_fg`），字和画面有前后关系
- **结构细节**：字形本身被设计过（切口、断笔、连笔、网格对齐的笔画）
- **精确的周边系统**：编号、细线、标签、坐标围绕巨字，形成"设计稿"的精度感

**禁止**：巨字用渐变填充 + 下沿淡出作为唯一处理（v0.3 示例第 2 轮就是这个问题）。

### 画框裁切：要么完整，要么大胆出血

被画框"切掉一点点"的东西看起来像做坏了，而不是设计：
- 字和图形**要么完整在画面内**（离边缘有呼吸空间），**要么明确出血**（裁掉 30% 以上，一看就是有意的）
- 不要切掉笔画末端、字符的一小半、图形的尖端或尾巴
- 用纹理 / 渐变填充（`background-clip: text`）的巨字特别容易被行框切掉笔画的上下端，模板已经自动加了绘制内边距；改模板时不要去掉
- 生成式图层的末端（流的尾巴、散开的星）要落在画面内，调 `--path` 的终点，不要靠裁切

## 四、生成式图层

很多当代技术 KV 的主画面是用代码生成的，而不是画出来或拍出来的。它天然具备三个优点：细节无限（放大仍然锐利）、和技术主题同源、每个尺寸可以单独生成而不是裁切。

`scripts/glyph_flow.py` 提供一种：由真实代码字符组成的流（散落的代码片段 → 单个字符 → 光点 → 汇聚的发光流）。适合"汇聚、流动、涌现、生长"类概念。

两种用法：
1. **纯生成式**：`<out>_hero.png` 直接作为主图，适合追求图形化、极简的方向
2. **混合**：生图模型出写实或 3D 主图，`<out>_layer.png` 叠在上面，代码字符流和写实场景结合

`scripts/glass_lens.py` 提供另一种：在成品上放一滴有折射、阴影、焦散的玻璃，透镜内可以显示另一张图（例如"补全后的代码"），适合"看见 / 放大 / 预见"类概念，也适合延续玻璃类品牌资产。做法是同一排版渲染两次（A / B，只在透镜要"变"的地方不同），再合成。**透镜要放在内容密集的区域**，放在空白处里面只有一片白。

生成式图层要**每个尺寸单独生成**（调整 `--path` 让流避开文字区），不要裁切。

## 五、高端品牌的减法

为 Apple 这类品牌做 KV 时，品质感主要来自**减法和渲染精度**，而不是信息系统：
- **一张图 + 一行字**：主画面满版；文字只保留品牌标识、日期、一句 tagline，其余信息放到延展物料里。顶栏、编号、标签网格、代码注释这类"系统感"元素会让画面像开发者工具的落地页，而不像品牌发布。
- **主体必须是高精度渲染或摄影**：玻璃、金属、光的质量就是品牌质量。程序生成的替身只能用来定构图，不能当成品评估。
- **品牌字体**：没有授权字体时，排版质量会直接掉一档，需要在交付时说明。

## 六、AI 感：信号与对策

用户一眼觉得"AI 感很强"，通常是下面几条叠在一起：

| AI 感信号 | 设计师的做法 |
|---|---|
| 到处发光：光晕、泛光、逆光、一层粉蓝雾，没有暗部 | 一个主光源，暗部保留；最多一处发光，其余是干净的反射和投影 |
| 全身人物，皮克斯式标准笑脸、张嘴、夸张弓步，手脚比例怪 | 只用**手**或局部肢体（抖音校招就是这样），或请插画师画角色；不用模型出全身人物做主角 |
| 一张图里有几个视角：人物仰拍、校园俯拍、平台平视 | 统一一个相机视角和一个比例尺 |
| 所有材质都是同一种糖果玻璃、彩虹渐变 | 2–3 种材质有对比：磨砂 vs 光面、金属 vs 软胶、玻璃 vs 纸 |
| 云上漂浮的城堡 / 校园、梦幻天空 | 落地的场景，或者干脆是纯色 / 渐变底上的物件 |
| 画面全部来自模型，文字只是贴在旁边 | **设计层压在图上**：网格、棋盘格、贴纸、标签、标题和物件互相穿插，边缘锐利 |
| 字面化的寓言：举着积木走上坡去找伙伴 | 用物件和关系表达，不演一个故事短片 |

**流程上的对策**：不让模型出整张场景，而是**分别生成单个素材**（白底或纯色底：一对手、一个道具、两三个物件），在排版里统一视角、比例、光和调色，再加设计层。整张场景的构图、比例和光由设计决定，模型只负责物件的质感。

## 七、自检问题

渲染后回答：
1. 对照第一节的表，命中了几条老气信号？
2. 遮住小字、缩到缩略图，能认出是这个活动吗？装置是什么？
3. 把最大的那个字放大到 100% 看，里面有东西吗？
4. 画面里一共有几种视觉语言（照片、3D、点、字符、线……）？超过 2 种就要删。
