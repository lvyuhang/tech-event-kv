# 延展：从定稿 KV 到全套物料

> 来源：天大 CANN 开发者俱乐部成立仪式（2026-11-03 至 11-06），一份定稿 KV 延展出 20 多件线上线下物料，经过 5 轮评审，用户评价"本次任务特别成功"。完整案例和配图：`examples/tju-cann/extension/`。对应经验 L48–L55。

## 0. 先看清这份延展是什么

1. **延展设计语言，不裁切素材**。把 KV 的格子裁下来填满新版面，是 v1 失败的原因（L48）。先把 KV 拆成**规则**和**组件**，每个画幅从规则重新排。
2. **先场景，后版式**。每件物料先写一句话：现场怎么被看、被用，被什么挡住（L49）。
3. **活动信息集中成一份配置**。方案到手后，所有时间、地点、议程、嘉宾只在一处维护（L55）。

## 1. 拆 KV：规则（≤ 6 条）+ 组件

本案的 6 条规则（像素便当格 KV）：

| # | 规则 | 检查方法 |
|---|---|---|
| 1 | 一切落在网格单元 u 上；黑描边 ≈ 0.035u，只描卡片，不描背景格 | 线宽统一，横竖线贯通 |
| 2 | 浅灰底 + 白网格；每张至少留约 20% 的空格子 | 有没有喘气的空格 |
| 3 | **标志画面**（台阶 01/02 + 黄橙绿三色斜条 + 彩色玻璃）按每个画幅**重新生成**，不裁切 | 编号、斜条、玻璃是否完整 |
| 4 | 出血的像素风景：顶部蓝色雪山向右散成像素点，底部绿色像素山压边 | 有没有尺度对比 |
| 5 | 标题卡永远是最大的格子，可带台阶缺口与邻格咬合 | 主次 |
| 6 | 标题用超粗黑体；编号、时间、日期用像素点阵字 | 字体分工 |

组件（代码见 `examples/tju-cann/extension/src/lib.py`）：
- `title_lockup`：标签 + CANN 字标 + 开发者俱乐部，可设缺口、居中
- `hero_field`：标志画面生成器（台阶、斜条、Voronoi 彩色玻璃），任意宽高、可无编号、可镜像
- `snow_peak` / `pixel_hill`：出血像素风景
- `icon`：从 KV 原稿按坐标裁出的像素图标（NPU、咖啡杯、海棠、运算符、成员卡、终端），不重画
- `pixtext`：5×7 点阵数字；`agenda_full`：议程表；`info_rows`：标签 + 值；`qr`：二维码占位；`bubble`：像素对话框

| 易拉宝 80×200 | 视线 1.5–1.7m ≈ 离顶 0.3–0.5m | 标题区在离顶 0.12–0.54m；二维码离地 1.1–1.3m；底部 15cm 只放装饰 |

## 3. 合影背板：先有玩法，再有画面

靠解释才成立的创意（"站进框里成为创始成员"、"+1 贡献山"）被评为无趣（L50）。借用户正例的**机制**（`library/items/2024-*`、`2025-*`）：

| 机制 | 身体做什么 | 本案落地 |
|---|---|---|
| 姿势 | 刻度 / 形状规定动作 | **NPU 今日算力体检 1P VS 2P**（采用）：圆心在离地约 1.4m，人站上去头挡住芯片＝"你就是今天的 NPU"，抬手当指针指向"摸鱼中 / 正常算力 / 满血运行 / 算子炸了" |
| 站位 | 每人一句"说的是我" | 开发者心声墙（备选）：大合影时只露顶部一排 |
| 场景 / 穿越 | 1:1 熟悉场景、穿门 | 需要立体道具，平面布做不了 |

交付必须附**人形剪影示意**（大合影 / 2–3 人 / 单人），用来验证遮挡和玩法。尺寸以清单为准，B 方案曾被擅自改成 2.4×2.4m（L51）。

## 4. 新信息到来时

1. 列"物料 × 要改什么"表交用户，标出清单变化（新增 / 取消 / 文案变化）。
2. 信息写进配置：`EVENT`（学校、标题、日期、时间、校区、场馆）+ `AGENDA`（时间、环节、嘉宾、职务、内容、类型 hi/minor）+ `GUESTS`。未定的写"待定"并灰色显示；方案注明"须核实"的姓名职务，交付时提醒。
3. 多校巡回："每场只改主题和高校信息"→ 学校相关模块（海棠、TJU、校名 logo）做成可替换槽位。

## 5. 交付格式

- 印刷：真实尺寸矢量 PDF（Chromium 打印，`printBackground`；超过约 5m 的横幅按 1:2 输出并注明）
- 线上：PNG（deviceScaleFactor 让长边 ≥ 3000px）
- 串场 PPT：Slides 在线可编辑 + 逐页 PNG（按用户给的屏幕尺寸，如 2580×1462）
- 每轮：总览图（contact sheet）+ 场景示意 + 占位 / 建议文案清单
