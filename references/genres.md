# 活动类型与视觉惯例

**不同类型的活动，"好"的标准不一样。** 先判断类型，再用该类型的惯例和评分权重。用一个类型的审美去做另一个类型（例如用高端品牌的"克制"去做校园招新），是方向性错误。

---

## A. 运营招募 / 校园类
（校园招聘、社团招新、高校宣讲、开发者俱乐部成立、训练营招募、学生竞赛）

**目标**：让年轻人第一眼觉得"好玩、想参加"，愿意转发。

**视觉惯例**（来自用户提供的抖音、快手、迅雷、稿定校招 / 招募 KV）：

| 维度 | 惯例 |
|---|---|
| 构图 | 标题居中或居左，周围环绕 **4–8 个悬浮的 3D 物件**，有前后景深、运动模糊、出画 |
| 物件 | 技术符号"潮玩化"：键帽、复古电脑、光标、代码窗口、文件夹、火箭、星星、地球；材质是玻璃、亚克力、毛绒、黏土、金属；常带表情（笑脸、眼睛） |
| 情感 / 人 | **手**（击拳、伸手邀请、握手）、角色背影、拟人化的 IP；直接表达"连接""邀请""加入" |
| 配色 | 高明度：白 / 浅蓝 / 淡紫 / 天蓝为底，点缀黄、绿、粉；通透的光感，大面积亮部 |
| 标题字 | **定制字**：粗、圆、斜切、速度线、立体或玻璃质感；副标题常用手写体或描边字 |
| 装饰 | 棋盘格、像素块、贴纸标签（FIGHTING! / JOIN US / Hello World）、星星、对话气泡 |
| 文字量 | 主标题 + 副标 + 1–2 个按钮 / 标签式信息 |

**这类 KV 的几个硬要求**：
- **技术元素长在物件上**：算子名印在键帽上、真实代码片段写在代码窗里、Merged 徽章、芯片里的光。不做电路板贴图、蓝色光束这类背景装饰。文字要具体可读（`add`、`__aicore__ void add_custom()`），不写泛泛的 "AI""CODE"。
- **"连接"用手或角色的动作画**：递和接、一起按、搭桥。避免直接复制参考里的动作（抖音是碰拳）。
- **标题通常是黑色粗体定制字**（不是彩色渐变字），亮底上对比最强；副标黑体，信息做成胶囊按钮。
- **物件呈弧形环绕标题区**，最大的物件不超过画面高度 25%，视觉重心在上半部分。
- **现场大屏兼作合影背景时**，底部 10–15% 只放装饰，标题上移。

**评分权重调整**：
- "克制"换成 **"丰富与亲和"**：物件够多、够有趣、有情绪；但主次清楚、标题不被淹没。
- "独特性"放低：用该类型的通用语言是**对的**，差异化来自主题物件和叙事，而不是另起一套风格。
- "概念"服务于风格：巧思是加分项，**好看、亲切、热闹是及格线**。

**主图路线**：3D 潮玩风格首选生图模型或 3D 设计师出主图（SKILL 路线 A / D）。没有生图模型时，可以用 three.js 的圆角几何体 + PBR 材质（玻璃透射、软胶清漆、毛绒 sheen、金属）+ 环境光搭出物件，前景单独一层做虚化和运动模糊，完成度可以接近成品（示例：`examples/tju-cann/v4/`）。手用圆角方块 + 胶囊拼，掌心朝上时要把手腕向镜头转约 1 rad，否则只看到侧边。

## B. 开发者大会 / 技术峰会
（年度开发者大会、技术峰会、AI 大会、云大会）

**目标**：权威、前沿、品牌感；现场大屏和舞台的统一视觉。
**惯例**：一个强主视觉符号（字形、材质、光）、暗场或白底、精确排版系统、可延展到舞台和导视。
**评分**：按 qa-checklist 的默认 8 维。参考 `case-studies.md`、`contemporary.md`。

## C. 品牌发布 / 高端品牌
（Apple 级别的发布会、旗舰产品发布）

**目标**：品质感、神秘感、品牌一致性。
**惯例**：一张图 + 一行字（`invite`），极致的渲染 / 摄影，品牌字体。
**评分**：以该品牌往届物料为基准（qa-checklist 评分校准）。

## D. 黑客松 / 技术社区
（黑客松、Meetup、开源社区活动、技术沙龙）

**目标**：极客、参与感、社区氛围。
**惯例**：终端 / 像素 / 代码作为主视觉语言（`terminal` 系统、D5、D6、D9），手作感、贴纸、梗。
**评分**：默认 8 维，"时代感与识别度"看是否懂开发者文化。

---

## 判断不清时

一场活动可能横跨两类（例如"开发者俱乐部成立仪式暨校园宣讲会" = A 为主、D 为辅）。按**受众**判断主类型：受众是学生 → A；受众是行业开发者 → B / D；受众是大众消费者 → C。在需求分析里写明判断和理由，交用户确认。
