# 活动类型与视觉惯例

**不同类型的活动，"好"的标准不一样。** 先判断类型，再用该类型的惯例和评分权重。用一个类型的审美去做另一个类型（例如用高端品牌的"克制"去做校园招新），是方向性错误。

---

## A. 运营招募 / 校园类
（校园招聘、社团招新、高校宣讲、开发者俱乐部成立、训练营招募、学生竞赛）

**目标**：让年轻人第一眼觉得"好玩、想参加"，愿意转发。

**视觉惯例**（来自用户提供的抖音、快手、迅雷、稿定校招 / 招募 KV）：

| 维度 | 惯例 |
|---|---|
| 构图 | 两种：① 标题居中，周围环绕 **4–6 个悬浮的 3D 物件**，有前后景深、运动模糊、出画；② **左文右图 + 一个连续的机制主体**（输入 → 过程 → 结果），物件附着在主体上（抖音生活服务搜索广告通案） |
| 物件 | 技术符号"潮玩化"：键帽、复古电脑、光标、代码窗口、文件夹、火箭、星星、地球；材质是玻璃、亚克力、毛绒、黏土、金属；常带表情（笑脸、眼睛） |
| 情感 / 人 | **手**（击拳、伸手邀请、握手）、角色背影、拟人化的 IP；直接表达"连接""邀请""加入" |
| 配色 | 高明度：白 / 浅蓝 / 淡紫 / 天蓝为底，点缀黄、绿、粉；通透的光感，大面积亮部 |
| 标题字 | **定制字**：粗、圆、斜切、速度线、立体或玻璃质感；副标题常用手写体或描边字 |
| 装饰 | 棋盘格、像素块、贴纸标签（FIGHTING! / JOIN US / Hello World）、星星、对话气泡 |
| 文字量 | 主标题 + 副标 + 1–2 个按钮 / 标签式信息 |

**先分清这类 KV 靠什么好看**：靠**调性和完成度**，不靠剧情。用户给的参考（抖音、快手、迅雷、稿定）都没有复杂叙事，最多一个动作（碰拳）或一个状态（窝在沙发里）。它们的好来自：第一眼好看、风格统一、标题字有设计、配色明快、物件精致又和主题相关。剧情放在文案里，不放在画面里。

**优先级**：① 调性与好看 → ② 标题字 → ③ 一个主符号或一个动作（满足"连接"之类的关系要求即可）→ ④ 主题相关的物件氛围。物件只要求"属于这个主题、风格统一、做工精致"，**不要求每个都在故事里有角色**；不要把 slogan 逐字演成画面。

**这类 KV 的几个硬要求**：
- **技术元素长在物件上**：算子名印在键帽上、真实代码片段写在代码窗里、Merged 徽章、芯片里的光。不做电路板贴图、蓝色光束这类背景装饰。文字要具体可读（`add`、`__aicore__ void add_custom()`），不写泛泛的 "AI""CODE"。
- **"连接"用手或角色的动作画**：递和接、一起按、搭桥。避免直接复制参考里的动作（抖音是碰拳）。
- **标题通常是黑色粗体定制字**（不是彩色渐变字），亮底上对比最强；副标黑体，信息做成胶囊按钮。
- **物件呈弧形环绕标题区**，最大的物件不超过画面高度 25%，视觉重心在上半部分。
- **人物用潮玩手办风格**（参考 library/2026-kuaishou-vote-toy）：搪胶 / 软胶材质、头身比约 3.5–4、五官简化，但穿搭是**成年人的潮流造型**（卫衣、工装裤、厚底鞋、头戴耳机、墨镜、配饰），有态度、很酷。不用皮克斯式写实比例的全身人物（AI 感强），也不用书包、校服、红领巾等低龄符号。
- **人物要有状态**：在做一件和活动相关的事（敲代码、庆祝合并、和伙伴击掌），姿态放松、有个性；不要标准笑脸和摆拍。
- **背景不能单一色相**：饱和蓝天也要有色相变化（深蓝 → 淡紫 → 地平线附近的粉桃色）、3D 软胶云、远处虚化的大形状，否则"太单调"（L38）。
- **建筑要写明 3D 潮玩材质**：只写"潮玩模型风格"不够，模型仍会出写实玻璃幕墙。要写：黏土 / 软胶质感、大块面纯色、圆角、窗户是简单的色块、没有写实反射，像积木或桌面摆件。
- **符号化的大道具要有设计**（如"门"）：给厚度、倒角、倾斜角度、发光的边缘、细节（标签页、代码行、键帽把手），并让它和地面、人物发生关系（门里延伸出键帽台阶），否则看起来"呆"。
- **不画写实场景**：纯色 / 渐变背景 + 一块简单地面 + 几件道具组成布景，像潮玩展示台；不要云上城市、写实校园、风景。
- **出图前的减法清单**（L36）：主体 1 个 + 配角物件 ≤ 3 个 + 点缀 ≤ 3 处；小方块、花瓣、星星这类"碎屑"总数 ≤ 10；文字块占画面面积 ≤ 35%，四周留出呼吸空间；3D 字效只用在主标题一处，其余文字平面；不加底部色带除非必须；天空 / 背景要有大片空白。**但减法只减"碎"，不减"张力"**：广角夸张透视、大小对比（近大远小）、光束、运动模糊、饱和的主色要保留；碎屑不删光，而是组织成一条有大小渐变的流（L37）。
- **宁少勿乱**：主角 1 组 + 左右各 2 个物件（共 4–6 个）就够热闹。物件角度控制在相近的范围内、左右成对；同一类东西只出现一次（不要三颗键帽 + 两张卡 + 四颗星）。小星星、闪光不超过 3 个。
- **标题字要精致，不要老气**：不用硬投影（偏移的实色阴影、多层挤出）、粗白描边、贴纸式外框、假斜体（把中文 skew 倾斜）——这些是 2015 年前后的电商 / 综艺字效。当下做法：干净的超粗黑体、字距收紧、英文单词用渐变填色、只加一层很柔的大半径投影；slogan 放进半透明磨砂胶囊，信息用黑色胶囊。
- **现场大屏兼作合影背景时**，底部 10–15% 只放装饰，标题上移。

**评分权重调整**：
- "克制"换成 **"丰富与亲和"**：物件够多、够有趣、有情绪；但主次清楚、标题不被淹没。
- "独特性"放低：用该类型的通用语言是**对的**，差异化来自主题物件和叙事，而不是另起一套风格。
- "概念"服务于风格：巧思是加分项，**好看、亲切、热闹是及格线**。

**两种主流视觉语言**（用户确认的方向）：
- **3D 潮玩**（抖音校招）：手 / 潮玩人物 + 悬浮物件 + 黑色定制标题字。主图需要生图模型；推荐**素材分开生成**（主视觉 + 每个漂浮元素各一张，共用风格段、纯白底、同一光向和视角，以主视觉作风格参考），再在排版里合成。漂浮元素选受众身边真实的东西再加技术内容（成员卡 No.0001、CANN 键帽、冒 "0 1" 热气的马克杯、手写矩阵乘的草稿本、有表情的 NPU 芯片、弹出 Merged 的笔记本）。示例：`examples/tju-cann/dirA/assets_dirA.md`。用户认可的元素写法（`approved_element_hello_cann.png`）：**一个受众熟悉的小设备 + 一块屏幕或表面"显示"一句很短的技术内容**（金属外壳 + 黑色小屏 + 亚克力键帽）。按这个公式扩展：扭蛋机里的算子扭蛋、显示 11:08 的闹钟（= 活动日期）、珍珠是小方块的奶茶、LEVEL 1 的掌上游戏机等，见 `assets_more.md`。
- **平面模块拼贴**（钉钉生态大会，library/2023-dingtalk-ecosystem）：浅灰网格底，所有元素是对齐网格的方块模块（纯色块 + 像素图标、字母块、扁平花朵、彩色玻璃马赛克、阶梯条纹、颗粒边缘的扁平云团），标题坐在白色方块里、阶梯错位，超粗黑体加镂空切口；亮蓝为主，橙绿黄撞色。**可以完全用代码做出成品**（路线 F），延展最方便。模块要**双重相关**：每个模块同时说"技术"和"受众"（方格纸 = 草稿纸 + 张量格；提交热力图点亮一格 = 第一份贡献 + 打卡；会员卡 No.0001 = 成立 + 学生证；像素咖啡杯冒 "0 1 0" = 写代码 + 熬夜），不用对话气泡、机器人头这类通用图标。示例：`examples/tju-cann/dirB/`。

**更多创意结构**（天大项目验证过，均可复用）：
- **载体借用**：把整张 KV 做成受众熟悉的一种"东西"，文案填进它固有的字段。登机牌（FROM/TO = slogan 的"从……到……"、航班号、登机口、座位 No.0001）、门票、学生证、课程表、终端窗口。平面，代码直出，能延展成真实物料。示例：`examples/tju-cann/dirC-boarding-pass/`。
- **贴纸堆**：一个表面（笔记本电脑盖、水杯、行李箱）贴满模切贴纸，标题是最大的那张。开发者文化 + 学生审美，每张贴纸都能单独做周边。示例：`examples/tju-cann/dirD-sticker-laptop/`。
- **场景微缩**：受众熟悉的一个现场做成潮玩微缩（社团招新摊位、实验室工位、宿舍书桌），标题写在场景里的横幅 / 招牌上。识别特征是场景的标志形状（遮阳棚 + 横幅 + 桌布）。示例：`examples/tju-cann/dirE-club-booth/`。

**主图路线**：3D 潮玩风格首选生图模型或 3D 设计师出主图（SKILL 路线 A / D）。没有生图模型时，可以用 three.js 的圆角几何体 + PBR 材质（玻璃透射、软胶清漆、毛绒 sheen、金属）+ 环境光搭出物件，前景单独一层做虚化和运动模糊，完成度可以接近成品（示例：`examples/tju-cann/v4/`）。手用圆角方块 + 胶囊拼，掌心朝上时要把手腕向镜头转约 1 rad，否则只看到侧边。

## B. 开发者大会 / 技术峰会
（年度开发者大会、技术峰会、AI 大会、云大会）

**目标**：权威、前沿、品牌感；现场大屏和舞台的统一视觉。
**惯例**：一个强主视觉符号（字形、材质、光）、暗场或白底、精确排版系统、可延展到舞台和导视。
**评分**：按 qa-checklist 的默认 8 维。参考 `case-studies.md`、`contemporary.md`。

## C. 品牌发布 / 高端品牌
（Apple 级别的发布会、旗舰产品发布）

**目标**：品质感、神秘感、品牌一致性。
**惯例**：一张图 + 一行字（`invite`），极致的渲染 / 摄影，品牌字体。
**评分**：以该品牌往届物料为基准（qa-checklist 评分校准）。

## D. 黑客松 / 技术社区
（黑客松、Meetup、开源社区活动、技术沙龙）

**目标**：极客、参与感、社区氛围。
**惯例**：终端 / 像素 / 代码作为主视觉语言（`terminal` 系统、D5、D6、D9），手作感、贴纸、梗。
**评分**：默认 8 维，"时代感与识别度"看是否懂开发者文化。

---

## 判断不清时

一场活动可能横跨两类（例如"开发者俱乐部成立仪式暨校园宣讲会" = A 为主、D 为辅）。按**受众**判断主类型：受众是学生 → A；受众是行业开发者 → B / D；受众是大众消费者 → C。在需求分析里写明判断和理由，交用户确认。
