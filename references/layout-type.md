# 版式与字体

## 信息层级（从强到弱）

| 层级 | 内容 | 相对字号（基准 = 画布短边） | 说明 |
|---|---|---|---|
| H1 主标题 | 活动名或核心主题 | 7–11% | 粗体，1–2 行；最重要的视觉文字 |
| H2 副标 | 英文名或主题句 | 2.2–3% | 和 H1 拉开明显差距 |
| Slogan | 主题口号 | 3.5–5% | 可选；与 H1 二选一做最大 |
| Meta | 日期、地点 | 2.5–3.5% | 日期用等宽数字（tabular-nums） |
| Eyebrow / 底注 | 届数、英文全称、网址 | 1.3–1.8% | 全大写 + 大字距（0.3–0.5em） |
| Logo | 主办方 | 高度 4–6% | 左上或右上 |

一张 KV 最多 4 个文字层级，多了就删。参考案例 Alibaba 只有 4 层：logo、H1+H2、slogan、底注。

## 版式

所有版式共用：外边距 = 画布短边 × 7%（大屏 6%，竖版 8%）。

- **L1 左文右图**：文字块左对齐，占左 38%，垂直居中略偏上；主图在右侧并出血。最通用。
- **L2 居中**：主体居中，文字在下方居中或压在主体前方（需加暗角 scrim）。适合正方形和对称符号。
- **L3 右信息栏**：主图占左 65%，右侧信息栏用细线分隔（WDCC 案例）。适合信息多的场景：分会场名、日期区间、二维码。
- **L4 满版文字**：大字号标题占满画面，主图退为背景纹理。适合 D4、D5。

**竖版（9:16、海报）**：L1 和 L3 都自动变成"上文下图"。

## 字体

模板默认按以下顺序回退，品牌有指定字体时在 config 里覆盖：

- **中文**：思源黑体 / Noto Sans SC → MiSans → 苹方 → 系统黑体
- **英文标题**：Inter / Space Grotesk / Manrope（几何无衬线）
- **数字与代码**：JetBrains Mono / IBM Plex Mono
- 字重对比：H1 用 700–900，其余 300–500。避免全部用同一字重。

## 排版细节

- 中文 H1 字距 `-0.01em` 到 `0`；英文 H1 字距 `-0.03em`；行高 1.05–1.15。
- 中英混排时英文单独一行，不要在同一行混排两种语言的大标题。
- 底注全大写加大字距，就是参考图那种 `F Y 2 7  G L O B A L` 的效果（`letter-spacing: 0.45em`）。
- 日期写法统一：`2026.12.11` 或 `12.11–12.12`；不要 `2026年12月11日`（太长）。
- 文字压在主图上时，对比度不够就开 `scrim`（文字一侧加渐变暗角），不要给文字加描边或投影。

## 安全区

- 大屏：底部 8% 可能被舞台遮挡，不放关键信息。
- 公众号头图：900×383 在转发卡片等场景可能只露出中间区域，所以一定要同时出一张 `square` 次图。
- 社媒竖版：顶部 12% 和底部 18% 会被 UI 覆盖。
- 印刷：四边留 3mm 出血，文字离裁切线 ≥ 5mm。
