# 主视觉符号提炼

KV 的记忆点几乎都来自一个**符号**：一个有辨识度的形态，经过材质化之后撑起整个画面。

## 五个来源，各出一个候选

| 来源 | 做法 | 例 |
|---|---|---|
| **Logo 形** | 取 logo 的轮廓或局部，放大、立体化、拆解 | WDCC 把 W 和 C 做成玻璃块；TCL 把 TIC 拆成碎片 |
| **活动名 / 缩写** | 取首字母、缩写、核心英文词，做 3D 字形 | Alibaba 的 "Global" 流体字 |
| **数字** | 年份、届数、版本号（"26"、"10th"、"v5"） | 大字号 "2026" 做成发光管 |
| **核心关键词** | slogan 里最有画面感的词，找它的形 | "连接" → 结；"生长" → 分形树；"开放" → 打开的环 |
| **技术隐喻** | 与领域相关、但不俗套的形态 | 见下表 |

## 技术隐喻素材库（可用）

| 领域 | 可用形态 |
|---|---|
| 通用编程 | 花括号 `{ }`、尖括号 `< />`、光标 `▍`、缩进阶梯、git 分支线、波浪线 `~` |
| AI / 大模型 | 层叠的半透明平面（神经网络层）、注意力连线、token 碎片流、渐进收敛的点云、星形 ✦ |
| 云 / 基础设施 | 模块化方块堆叠、等距服务器塔、层层嵌套的容器 |
| 数据 | 流线、等高线、柱状体雕塑、散点星图 |
| 芯片 / 硬件 | 晶圆的同心圆、几何走线（只取走线的节奏，不要整块电路板贴图） |
| 安全 | 锁扣结构、多层同心护盾、几何晶格 |
| 开源 / 社区 | 环、交织的线、拼插积木、众多小点组成大形 |
| 移动 / 终端 | 圆角矩形、手势轨迹 |

## 俗套清单（默认禁用，除非用户坚持）

二进制数字雨、发光大脑、机械手与人手指尖相触、蓝色地球 + 连线、整块电路板贴图、人形机器人脸、锁 + 盾的图标、"科技蓝"渐变配白色光点、齿轮、灯泡。

## 挑选标准

候选符号逐条判断，三条都满足才进入方向：

1. **可识别**：缩小到 200px 宽还能看出是什么。
2. **可材质化**：有足够的体积或线条，能赋予玻璃、金属、流体等材质。纯平面图形要先想好怎么"立"起来。
3. **能撑画面**：放大后能占画面 40–70%，又不显得空。

## 符号的处理方式

同一个符号，可以用不同的处理方式做出差异：

- **整体放大出血**：主体超出画面边缘，只露局部（Alibaba 案例）
- **作为容器**：符号内部合成别的画面（WDCC 案例，形内是城市）
- **拆解散落**：拆成碎片悬浮（TCL 案例）
- **重复阵列**：同一符号大量重复成纹理
- **生长 / 流动**：符号由线、粒子或流体正在形成的过程
