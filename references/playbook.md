# 实战手册：运营 / 赛事类 KV（v3.0）

> 从天大 CANN 开发者俱乐部项目（2026-10-29 至 10-31，30 多轮评审）提炼。每条后面是对应的经验编号（`lessons.md`）。新项目先读这一页。

## 一、先想清楚再画

1. **需求分析是第一道关**：活动类型、主办方背景（用搜索核实）、受众认知、关键词、风格翻译、必须表达的关系、使用场景、文案层级、约束。产出验收清单 + 待确认问题。（L19）
2. **类型决定审美**：校园 / 运营 / 年轻赛事是**调性优先、叙事轻量**——第一眼好看、风格统一、标题字有设计、配色明快；不要把开发者大会的"概念推导"套过来，更不要把 slogan 逐字演成画面。（L20、L31）
3. **主物料决定创意能不能用**：先问"这是大屏、线上，还是线下印刷板"。印刷板：远看、人挡下半部、logo 要醒目、放大倍数大、CMYK。信息字段多的载体（登机牌）、主体在中下部的场景（摊位）、由小块组成的拼贴，都不适合做主 KV。（L33、L34）
4. **用户确认的约束要记成清单**，每次出提示词前过一遍（例：不提"北洋"、人物是大学生、不要写实场景、logo 占位、未核实的事实不写）。

## 二、参考图是方向盘

5. **用户给的参考优先级最高**；看不到图时必须要参考。（L21）
6. **参考迁移**：骨架和语言照搬，语义按槽位替换；**换内容不换形状**（路牌还是路牌）；保持参考的元素数量和留白；先找出参考的识别特征，迁移后逐条核对。（`reference-transfer.md`、L32）
7. 迁移时写一张"槽位 | 参考里 | 换成 | 为什么"的表，用户一眼能看懂取舍。

## 三、画面怎么才"大气、不碎、不 AI"

8. **一个主体**：活动名本身（3D 字 / 每个字母一种材质）、一个大符号（门、C 环、计算机），或一个动作（交接、装键帽）。配角物件 ≤ 3，点缀 ≤ 3，碎屑 ≤ 10，文字块 ≤ 画面 35%。（L34、L36）
9. **减法只减碎，不减张力**：透视（广角仰视、近大远小）、光（体积光、轮廓光）、运动（流、模糊）、饱和主色都要留。（L37）
10. **背景要有层次**：多点色相渐变、软云 / 虚化大形状 / 透视网格 / 颗粒，不能单色平涂。（L35、L38）
11. **避免 AI 感**：一个主光、保留暗部、不泛光不起雾；统一视角；材质有对比；不用皮克斯式全身人物；加设计层；必要时素材分开生成再合成。（L29）
12. **大道具要有设计**：厚度、倒角、倾斜、发光边、细节，并和地面 / 人物发生关系，否则"呆"。建筑写明黏土 / 软胶材质、窗户是色块。（L38）

## 四、元素怎么选

13. **双重相关**：每个元素同时说"技术"和"受众"。公式：**受众熟悉的小设备 / 物件 + 一块屏幕或表面显示一句很短的技术内容**（"> hello, CANN_" 键帽设备、显示 11:08 的闹钟、写着算子名的扭蛋）。（L23、用户认可元素）
14. 不用通用程序员潮玩（复古电脑、火箭、`</>`、光标堆）；不用术语墙；画面里的代码 / 标签 ≤ 2 处。（L26、L27）
15. **人物**：潮玩手办风（成人潮流穿搭、简化五官、在做和活动相关的事），或者干脆不放人；不画小孩；不画写实场景。（L28、L30）
16. 技术氛围可以放在背景层：张量方块流、透视网格、极淡的真实代码纹理、字母标注线、一行终端命令小字。（L35）

## 五、文字

17. **层级按用户确认的来**：活动全称（含"成立仪式暨……"这类副标题）是一组；slogan 单独一层；时间地点最弱。
18. **印刷用中文由矢量排版**：生图模型的中文只用来看效果；正式稿标题自己排。
19. 中文排版对齐网格（左右两栏对齐主体边缘），不全部居中堆叠；不用硬投影、粗白描边、贴纸外框、中文假斜体。（L25、L35）

## 六、提示词（image-2）

20. **分段结构**：任务 / 活动 / 背景 / 主体 / 物件 / 场景 / 文字 / 风格与光 / 不要。文字用引号逐字给出并写"语言 zh，逐字准确"。（`prompt-recipes.md`）
21. **材质库**：拆参考 → 编号材质 → 逐部位指定，中英并写。（`materials` 写法）
22. **局部修改**：保留什么 → 标注图 → 每块一条编辑提示词、一次改一块、蒙版只画在框内。
23. 每个提示词后附"挑图看这几点"和"出图问题 → 补充句"。
24. 改一处就只改那一处：用户说"背景单调"，不要顺手重做主体。

## 七、交付

25. **标准交付 = 设计 Brief + 视觉提示词包**（`templates/`）。日常迭代可以直接在对话里给一段可复制的提示词。
26. 方向阶段给 2–3 个方向 + 推荐 + 可复制提示词；同时列待确认问题，不让对话停住。
27. 成品：主图 + 矢量重排的标题 + logo 占位 + 底部安全区；用于印刷时说明分辨率要求（宽 ≥ 12000px 或 3D 重建）。
