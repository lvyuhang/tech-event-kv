# 自检

分两部分：**不出错**（硬性检查）和**够好看**（审美评分）。v0.1 只有前者，所以能保证不出错，但保证不了好看。

用 Read 打开 `out/contact_sheet.png` 和每张单图逐项检查。

---

## 一、硬性检查（任一项不过必须修）

**内容**
- [ ] 活动名、日期、地点与 brief 逐字一致（尤其是数字）
- [ ] 主图里没有模型生成的乱码文字、水印、假 logo；字形主体拼写正确
- [ ] 点缀信息（坐标、届数、编号）是真实的，不是编的
- [ ] 没有俗套元素（concept.md 俗套清单），没有落进参考调研的红海清单
- [ ] 和参考作品放在一起对比：构图、图形、配色组合都不雷同

**字体**
- [ ] `render.py` 输出里没有 ⚠ 字体警告；有警告就补字体文件或改字体栈，不能带着默认字体交付
- [ ] 全画面 ≤ 2 个字体家族 + 1 个等宽

**可读性**
- [ ] 标题在缩略图（宽 300px）下可读
- [ ] 文字没有压在主体最亮、最复杂的部位；信息单元没有压在主体上
- [ ] 所有文字在安全区内（typography.md 第四节）

**延展**
- [ ] 每个尺寸主体都在画面里，没有被裁掉关键部位
- [ ] 横竖版都有专用主图；方图和头图的主体没有和标题重叠

## 二、审美评分（每项 1–5 分）

| 维度 | 1 分的样子 | 5 分的样子 |
|---|---|---|
| **概念** | 关键词直译、俗套图标（L0/L1） | 画面本身讲了主张，看完能复述"这张图在说什么"（L3） |
| **第一眼冲击** | 缩小到手机屏幕上什么都不突出 | 3 米外/缩略图里一眼被主体抓住 |
| **融合** | 主体像贴纸，背景像壁纸 | 光、雾、倒影把主体和环境连成一个世界（integration.md 自检全过） |
| **字体** | 系统默认字体，粗细字号都差不多 | 字体有性格且与概念匹配，字号/字重对比强烈 |
| **排版系统** | 文字从上往下堆 | 有网格、有细线和标签系统，每个元素都对齐到某个东西 |
| **图文一体** | 文字浮在图上 | 有取色、穿插、颗粒覆盖，文字像在画面里 |
| **克制** | 元素多、颜色多、特效多 | 一个主体、一种材质、2–3 个颜色，每个元素都有理由 |

**合格线：总分 ≥ 26，且没有任何一项 ≤ 2 分。**

不合格时，按最低分的维度回到对应步骤：

| 最低分 | 回到 |
|---|---|
| 概念 | concept.md 第 3 步重新发散 |
| 冲击 / 融合 | prompt-recipes.md 改提示词，重生主图 |
| 字体 / 排版系统 | typography.md 换字体配方或排版系统 |
| 图文一体 | integration.md 第二节：开 `hero_fg`、调 `fx`、换 `title_fill` |
| 克制 | 删元素：去掉 slogan 或点缀，减少颜色 |

最多迭代 3 轮。评分表和每轮修改写进 `concept.md` 末尾，交付时附上。

**打分要诚实**：如果只是"没出错"，那是 3 分不是 5 分。拿参考调研里的"天花板"作品和 case-studies.md 的案例做对照——参考案例在这张表上大约是 30 分。

## 常见问题 → 修复

| 问题 | 修复 |
|---|---|
| 文字压在主体上 | 调 `focal`；换 `text_side`；该尺寸换排版系统 |
| 浅色主图上白字看不清 | `theme: light`；或加大 `fx.haze` |
| 巨字太抢、遮住了场景 | `title_fill: fade`（默认）或 `outline`；降低 `mark_width` |
| 巨字和主体没有前后关系 | 生成 `hero_fg`（scripts/cutout.py）；环境元素（银河、光束）也可以进前景 |
| 巨字挡住了画面的叙事焦点 | `mark_baseline` 让巨字立在地平线上；或降低 `mark_width` |
| 取色只有一个色相 | 检查 render.py 输出的取色；在 `palette.glow` 手动指定第二色 |
| 标题看起来发虚 | 降低 `fx.glow`，浅色画面设为 0 |
| 颜色和主图不搭 | 确认 `color_from_hero: true`；或在 `palette` 里手动指定 |
| 方图里文字太挤 | 该尺寸 `type_system: center`，或缩短 `h1` 为两行 |
| 主图拼错字 | 重新生成主图，不在排版层补救 |
