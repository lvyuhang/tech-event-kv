# 自检清单

逐条检查 `out/contact_sheet.png` 和每张单图。不通过的写明修复方法，重新渲染。

## 主图
- [ ] 主体完整可辨认，没有被版式文字遮挡关键部分
- [ ] 字形主体拼写正确（逐字母核对）
- [ ] 画面里没有模型生成的乱码文字、水印、假 logo
- [ ] 没有俗套元素（见 motif.md 俗套清单）
- [ ] 材质统一，只有一种主材质

## 排版
- [ ] H1 在缩略图尺寸（宽 300px）下仍可读
- [ ] 文字与背景对比度：H1 ≥ 4.5:1，小字 ≥ 7:1；不够就开 `scrim` 或换文字色
- [ ] 文字层级 ≤ 4 级，H1 与次一级字号差 ≥ 2.5 倍
- [ ] 所有文字在安全区内（见 layout-type.md）
- [ ] 日期、地点、活动名与 brief 完全一致（逐字核对，尤其是数字）
- [ ] 中英文没有在同一行混排大标题

## 延展
- [ ] 每个尺寸主体都还在画面里，裁切没有切掉主体关键部位
- [ ] 出公众号头图时同时出了 `square` 次图，且两张都能看出活动名
- [ ] 竖版文字没有落在顶部 12% 和底部 18% 的 UI 遮挡区
- [ ] 所有尺寸的配色、字体一致

## 常见问题 → 修复

| 问题 | 修复 |
|---|---|
| 文字压在主体上 | 调 `focal` 让主体远离文字侧；或换版式 |
| 浅色主图上白字看不清 | `theme` 改 `light`（深色字），或开 `scrim` |
| 裁切后主体太小 | 该尺寸单独设 `zoom`（如 1.2） |
| 正方形里文字太挤 | 该尺寸 `layout` 改 `L2` |
| 主图拼错字 | 重新生成主图，不在排版层补救 |
