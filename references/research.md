# 参考调研

在概念推导之前，先去网上看同类活动的 KV。目的有三个：

1. **找到天花板**：同类活动做到了什么完成度，我们的目标就定在那里。
2. **找到红海**：哪些画面、手法、配色已经被用滥了。撞上了，独特性就是低分。
3. **借手法，不借形态**：看别人"怎么做"（隐喻手法、融合方式、排版系统），而不是"做了什么"（具体的图形）。

调研结果写进 `concept.md` 的"参考调研"一节，并在 concept.md 第 5 步打"独特性"分时引用。

---

## 一、调研范围（三圈）

| 圈 | 找什么 | 数量 |
|---|---|---|
| **本活动往届** | 这个活动历届的 KV。决定延续什么（品牌资产）、避免重复什么 | 能找到的全部 |
| **同类活动** | 同主题（AI / 云 / 开源 / 黑客松……）、同量级的活动，近 2 年 | 10–20 张 |
| **跨界灵感** | 与概念有关的非技术领域作品：音乐节、展览、品牌广告、电影海报、建筑摄影 | 5–10 张 |

第三圈最容易被忽略，但它是避免"技术活动长得都一样"的关键。

## 二、去哪里找

**设计作品平台**（搜索时加 `site:`）
- 国内：站酷 `zcool.com.cn`、花瓣 `huaban.com`、优设 `uisdc.com`
- 国际：Behance `behance.net`、Dribbble `dribbble.com`、Pinterest、Savee `savee.it`
- 字体与排版：Fonts In Use `fontsinuse.com`、Typewolf

**活动官网与官方社媒**：KV 的最终版本和延展物料通常在官网首屏、官方公众号头图、官方 X / 微博 / 小红书账号里。

**常见技术活动（按需检索其最近一届）**
- 国内：云栖大会、华为开发者大会 HDC、腾讯全球数字生态大会、百度世界、火山引擎 Force、WAIC 世界人工智能大会、小米开发者大会、QCon、ArchSummit、KubeCon China、各类 AI 开发者大会与黑客松
- 国际：Apple WWDC、Google I/O、Microsoft Build、AWS re:Invent、GitHub Universe、Figma Config、Vercel Ship、Stripe Sessions、Cloudflare 开发者周、NVIDIA GTC

活动列表会过时。以检索结果为准，优先最近一届。

## 三、检索词

按"活动名 / 主题 + 物料类型 + 平台或年份"组合。每轮 3–5 个检索词，中英文都要搜。

```
<本活动名> 主视觉 / KV / 海报 / 往届
<主题> 大会 主视觉 KV 设计            例：AI 开发者大会 主视觉 KV
<主题> 峰会 视觉设计 site:zcool.com.cn
<主题> conference key visual          例：developer conference key visual 2026
<主题> summit branding site:behance.net
<活动名> keynote stage design / event identity
<概念关键词> poster / campaign        例：firefly swarm poster（跨界灵感）
```

图片搜索优先；网页搜索用来找官网和设计师的项目说明（项目说明里常有设计思路，是最有价值的部分）。

## 四、怎么用工具

- 有网页搜索 / 图片搜索工具：直接用。用 Read 或图片查看能力打开结果，**要真的看图**，不能只看标题。
- 有的图片搜索工具只把结果展示给用户，执行者自己看不到图。这时**优先找设计方的项目页和案例说明**（Studio、设计公司官网、站酷/Behance 的项目文字、数英网案例），它们讲清了概念和手法，文字也读得到。拆解表里没看过原图的条目要标"（据说明）"，并请用户补充几张原图确认。
- 能下载图片：保存到项目的 `refs/` 目录，文件名用 `序号_来源_简述.jpg`，然后用 `scripts/moodboard.py` 生成情绪板。
- 网站拒绝访问、图片无法下载：记录链接和文字描述即可，不要绕过网站的限制。
- 没有任何联网工具：告诉用户，请用户发 5–10 张参考图；同时用 case-studies.md 的案例作为基础参考。

## 五、拆解与归纳

每张入选的参考按下表记一行（格式与 case-studies.md 一致，精简版）：

| # | 作品 / 来源 | 概念与手法 | 直白度 | 融合方式 | 排版系统 | 借鉴点 | 规避点 |
|---|---|---|---|---|---|---|---|
| 1 | 某云大会 2025 · 官网 | 置换：logo 字形 × 液态玻璃 | L1.5 | 暗场 + 光溢出 | 左文右图，接近 swiss | 光溢出到地面的做法 | 玻璃字形已经很多人用 |

然后归纳三张清单，写进 concept.md：

1. **红海清单**：出现 ≥ 3 次的画面、手法、配色。例："彩色玻璃字形 + 白底"、"紫色暗场 + 粒子"、"等距立方体"。**我们的方向不能落在这里**，除非执行完成度明显高于它们。
2. **天花板**：完成度最高的 2–3 张，以及它们高在哪里（材质？光？排版？）。
3. **可借手法**：值得借用的手法，写成"手法"而不是"形态"。例："巨字下沿淡入环境"（可借），而不是"做一个和 XX 一样的流体字"（不可借）。

## 六、情绪板

```bash
python scripts/moodboard.py refs/ --out refs/moodboard.jpg
# 或用清单文件附加说明：
python scripts/moodboard.py refs/list.json --out refs/moodboard.jpg
```

`list.json` 格式：`[{"file": "01_xxx.jpg", "title": "某大会 2025", "note": "借：光溢出；避：玻璃字形"}]`

情绪板在第 3 步和方向一起给用户看，说明每个方向和参考之间的关系：哪里借了手法、哪里刻意避开了。

## 七、边界

- 参考作品的版权属于原作者。**只借手法，不复制形态**：不临摹构图、不复刻特定图形、不直接用别人的配色组合。
- **不要把别人的 KV 当作图生图或风格参考的输入**传给生图模型。用户自己的品牌物料和往届 KV 除外。
- 情绪板只用于内部讨论，不放进交付物料。
- 引用来源要附链接，写进 concept.md。
