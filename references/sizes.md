# 延展尺寸表

config 里 `sizes` 每项格式：`{"name": "...", "w": 1920, "h": 1080, "hero": "heroes/hero_16x9.png"}`。`hero` 省略时用 `config.hero` 的默认主图并按 `focal` 裁切。

## 核心套装（默认渲染）

| name | 尺寸 px | 比例 | 用途 | 主图 |
|---|---|---|---|---|
| `screen_16x9` | 1920×1080 | 16:9 | 主会场大屏、PPT 封面、直播背景 | 16:9 专用 |
| `poster_9x16` | 1080×1920 | 9:16 | 竖版海报、朋友圈、视频号、小红书竖图 | 9:16 专用 |
| `wechat_cover` | 900×383 | 2.35:1 | 公众号头条封面 | 用 16:9 裁切 |
| `square` | 1080×1080 | 1:1 | 公众号次图、社群、头像框 | 用 16:9 裁切 |

## 按需尺寸

| name | 尺寸 px | 用途 |
|---|---|---|
| `screen_4k` | 3840×2160 | 4K 主屏 |
| `led_wide` | 按场馆给定 | 超宽 LED，如 7680×1080（32:4.5）；需要专门生成一张超宽主图 |
| `xhs_3x4` | 1080×1440 | 小红书 3:4 |
| `banner_web` | 1920×600 | 官网首屏横幅 |
| `live_cover` | 1280×720 | 直播间封面 |
| `email_header` | 1200×400 | 邮件头图 |
| `badge` | 900×1350 | 胸牌（印刷用 300dpi 时另算） |
| `rollup` | 800×2000 mm | 易拉宝，导出 2362×5906 px（75dpi 足够）；需要 9:16 主图上下扩展 |

## 主图分配规则

1. 16:9 和 9:16 必须各有专用主图（构图完全不同）。
2. 比例在 1.6–2.5 之间的横幅用 16:9 主图裁切；0.5–0.8 的竖图用 9:16 主图裁切；正方形用 16:9 裁切并通常切换到 L2 居中版式。
3. 比例超过 3:1 的超宽屏（LED）要单独生成主图。
4. 裁切依赖 `focal`（主体中心点，0–1 坐标）。设置方法：用 Read 看主图，估计主体中心的位置。
