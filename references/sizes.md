# 延展尺寸表

config 里 `sizes` 每项格式：`{"name": "...", "w": 1920, "h": 1080, "hero": "heroes/hero_16x9.png"}`。`hero` 省略时用 `config.hero` 的默认主图并按 `focal` 裁切。

## 核心套装（默认渲染）

| name | 尺寸 px | 比例 | 用途 | 主图 |
|---|---|---|---|---|
| `screen_16x9` | 1920×1080 | 16:9 | 主会场大屏、PPT 封面、直播背景 | 16:9 专用 |
| `poster_9x16` | 1080×1920 | 9:16 | 竖版海报、朋友圈、视频号、小红书竖图 | 9:16 专用 |
| `wechat_cover` | 900×383 | 2.35:1 | 公众号头条封面 | 用 16:9 裁切 |
| `square` | 1080×1080 | 1:1 | 公众号次图、社群、头像框 | 用 16:9 裁切 |

## 按需尺寸

| name | 尺寸 px | 用途 |
|---|---|---|
| `screen_4k` | 3840×2160 | 4K 主屏 |
| `led_wide` | 按场馆给定 | 超宽 LED，如 7680×1080（32:4.5）；需要专门生成一张超宽主图 |
| `xhs_3x4` | 1080×1440 | 小红书 3:4 |
| `banner_web` | 1920×600 | 官网首屏横幅 |
| `live_cover` | 1280×720 | 直播间封面 |
| `email_header` | 1200×400 | 邮件头图 |
| `badge` | 900×1350 | 胸牌（印刷用 300dpi 时另算） |
| `rollup` | 800×2000 mm | 易拉宝，导出 2362×5906 px（75dpi 足够）；需要 9:16 主图上下扩展 |

## 主图分配规则

1. 16:9 和 9:16 必须各有专用主图（构图完全不同）。
2. 比例在 1.6–2.5 之间的横幅用 16:9 主图裁切；0.5–0.8 的竖图用 9:16 主图裁切；正方形用 16:9 裁切并通常切换到 L2 居中版式。
3. 比例超过 3:1 的超宽屏（LED）要单独生成主图。
4. 裁切依赖 `focal`（主体中心点，0–1 坐标）。设置方法：用 Read 看主图，估计主体中心的位置。

## 线下印刷主视觉板 / 背景板（创意阶段就要考虑）

用户说"线下打印的 KV 板子 / 背景板 / 签到墙"时，下面几条会**直接淘汰一部分创意**，在第 2 步提方向之前就要过一遍：

| 约束 | 对创意的影响 |
|---|---|
| **远看**（3–15 米） | 只有大字和大色块读得出；小字段、标签、条形码、二维码、细线、小贴纸都会变成噪点。信息字段多的"载体借用"（登机牌、票据、证件）不适合做板子，适合做手持物料 |
| **人站在前面**（合影、致辞、揭牌） | 画面中下部约 1/3–1/2 会被人挡住：标题、slogan、logo 放上半部；中间靠下不能放关键内容。主体在画面正中下方的构图（摊位、桌面、场景微缩）会被挡掉一半 |
| **logo 必须清楚** | 背景板的 logo 区通常要求醒目、靠上，常见做法是顶部一排或左上角 |
| **放大倍数大**（3–6 米宽） | 矢量 / 代码直出的平面图形可以无限放大；生图模型出的位图要超分到足够尺寸（宽 ≥ 12000px 较稳妥），细节会糊、AI 痕迹会被放大 |
| **印刷色域（CMYK）** | 荧光、霓虹、镭射、自发光效果印不出来，会发灰；高饱和亮蓝和薄荷绿要打样确认 |
| **画幅不一定是 16:9** | 背景板常见 3×2 米、4×2.4 米、6×3 米等，先问尺寸，再定构图 |

**主 KV 要"大气"**：一个主体 + 一行大字 + 一条 slogan，元素少而大。模块拼贴、贴纸堆这类由很多小块组成的创意，远看会碎，用户明确否定过（L34）。最稳的做法是**把活动名本身做成主体**（3D 立体字 / 超大字），再用一两个符号赋予气质（如终端提示符 ">" 和光标 "_" 让字变成一行命令 → 一眼技术）。示例：`examples/tju-cann/dirF-big-type/`。

**适合做板子的创意**：大字主导、构图上重下轻、大色块、元素少而大、可以按任意比例重排（模块拼贴、大字排版、左右分列的标题 + 上部主体）。
